# 行为心理学技能包

将行为心理学理论转化为**可操作的编剧工具**。不是心理学教科书，是角色行为设计和观众心理操控的工具箱。

---

## 一、角色动机引擎

### 马斯洛需求下坠法

为每个主角标记三个需求层次定位点，定义角色弧线：

```
{角色名} 需求弧线
════════════════

故事开始时：{哪一层}（生理/安全/归属/尊重/自我实现）
最低跌到：{哪一层}
故事结束时：{哪一层}

弧线类型：{上升/下降/V形/倒V形}
```

| 需求层 | 角色状态 | 故事功能 |
|-------|---------|---------|
| 生理 | 活着就好 | 生存故事的底层 |
| 安全 | 需要稳定 | 威胁和危机的根源 |
| 归属 | 需要被接纳 | 关系线的驱动力 |
| 尊重 | 需要被认可 | 权力和地位冲突 |
| 自我实现 | 寻找意义 | 主题层面的追求 |

### Truby 需求/欲望对

- **欲望**（Desire）= 角色自己知道的外部目标
- **需求**（Need）= 角色不知道的深层缺陷的解药
  - 心理需求：克服某个伤害自己的弱点
  - 道德需求：停止伤害他人

**故事 = 角色追逐欲望的过程中，被迫面对需求。**

## 二、角色心理设计工具

### 1. 大五人格卡片（OCEAN）

为每个角色在五维度上打分（1-10）：

```
{角色名} OCEAN 卡片
═══════════════════

O 开放性：{分} — {高=好奇创新/低=保守固执}
C 尽责性：{分} — {高=有序可靠/低=随性冲动}
E 外向性：{分} — {高=话多主动/低=沉默内向}
A 宜人性：{分} — {高=合作温和/低=对抗强硬}
N 神经质：{分} — {高=情绪波动/低=冷静稳定}

压力反应预测：{基于OCEAN，这个角色面对危机时会怎样}
```

**冲突设计工具：** 把维度相反的角色放在一起。

### 2. 依恋类型配对

| 配对 | 戏剧效果 |
|------|---------|
| 焦虑+回避 | 最强推拉张力：一追一逃 |
| 安全+焦虑 | 治愈叙事 |
| 回避+回避 | 冰冷对峙 |
| 混乱+任何 | 高度不可预测 |

```
{角色名} 依恋类型：{安全/焦虑/回避/混乱}
被拒绝时第一反应：{追赶/撤退/崩溃/不可预测}
这个反应模式贯穿全剧。
```

### 3. 防御机制指定

为每个角色指定 1-2 个主要防御机制：

**不成熟防御：**
- 否认：假装没发生
- 投射：把自己的问题归咎于他人
- 退行：退回到更幼稚的行为

**神经质防御：**
- 合理化：编造合理理由（话多、逻辑严密但回避情感）
- 反向形成：做与真实感受相反的事
- 置换：把对A的怒气发泄到B身上

**成熟防御：**
- 升华：把痛苦转化为创作/工作
- 幽默：用笑化解痛苦
- 利他：通过帮助他人处理自己的痛苦

**角色弧线的心理学定义：**
- 成长型：不成熟防御 → 成熟防御
- 堕落型：成熟防御 → 不成熟防御

## 三、情境行为设计

### 认知失调 — 角色内心撕裂引擎

当角色的信念与行为产生矛盾时，三条故事分叉：
1. **改变信念** = 角色成长
2. **否认行为** = 悲剧种子/自欺
3. **合理化** = 道德滑坡的开始

```
失调设计
════════

信念：{角色相信什么}
矛盾行为：{做了什么违背信念的事}
解决路径：{改变信念/否认/合理化} → {故事后果}
```

### 习得性无助 — 角色困境设计

构建"笼子"：让角色在三次独立事件中失败 → 第四次机会出现时角色不行动 → 需要外部刺激打破无助。

### 情境腐蚀 — 环境改变人

权力 + 消除问责 + 群体压力 = 行为堕落。不需要角色"本性邪恶"。

```
腐蚀设计
════════

步骤1：{小恶，被忽视或被奖励}
步骤2：{稍大的恶，理由看似合理}
步骤3：{更大的恶，已经找不到"停下来"的界线}
```

### 操作性条件反射 — 行为塑形

角色过去被奖励过什么行为，就会在压力下本能重复：
- 因撒谎获益 → 压力下本能撒谎
- 因暴力解决问题 → 压力下本能暴力
- 间歇性强化 = 成瘾叙事（赌徒、情感依赖者）

## 四、观众心理操控

### 认知偏差利用表

| 认知偏差 | 编剧应用 |
|---------|---------|
| **确认偏误** | 角色只看到支持自己判断的证据——观众喊"你怎么看不到！" |
| **沉没成本** | 角色因"已经付出太多"而拒绝放弃错误路线——悲剧核心机制 |
| **锚定效应** | 先给观众一个初始印象（锚点），后续判断被锚点扭曲——误导工具 |
| **基本归因错误** | 角色把别人的行为归因于"品性"而非"情境"——冲突主要来源 |

### 共情建立三步法

1. 让角色做观众认同的小事（对服务员说谢谢）
2. 让角色展示脆弱（独处时的疲惫）
3. 给角色一个不公正的遭遇（观众自动站队）

### McKee 鸿沟驱动

每个场景：角色期望 X → 得到 non-X → 被迫升级行动。
鸿沟逐渐加大：第一幕"不方便" → 第二幕"危险" → 第三幕"生死攸关"。

## 五、非言语信号设计（Paul Ekman）

### 七种基本情绪的身体信号

| 情绪 | 面部（写进剧本） | 身体 |
|------|----------------|------|
| **愤怒** | 眉头下压聚拢，嘴唇紧抿 | 身体前倾，拳头握紧 |
| **恐惧** | 眉毛上扬并聚拢，嘴唇水平拉伸 | 身体后缩，肩膀上提 |
| **悲伤** | 眉头内侧上扬，嘴角下拉 | 肩膀下沉，动作变慢 |
| **厌恶** | 上唇上提，鼻子皱起 | 身体后仰，头微侧 |
| **惊讶** | 眉毛全面上扬，下巴下落 | 手部定格在半空 |
| **快乐** | 嘴角上扬，眼角鱼尾纹 | 身体放松打开 |
| **蔑视** | 单侧嘴角上扬（不对称） | 头后仰，目光从上往下 |

### 微表情泄露写法

角色掩饰时，真实情绪以微表情闪过。不写"他在说谎"，写：

```
❌ "他在说谎。"
✅ "他说'我没事'的时候，嘴角有一瞬间向下抽了一下。"

❌ "她假装不介意。"
✅ "她笑着说'当然不介意'，但笑意没有到达眼角。"

❌ "他讨厌这个人。"
✅ "他听到这个名字时，鼻翼微微抽动了一下，然后若无其事地继续喝咖啡。"
```

### 身体语言矛盾法

当角色说谎或掩饰时，让**言语和身体产生矛盾**：

```
言语说"没事" + 手在桌下攥紧纸巾 = 观众读出真相
言语说"当然" + 身体后仰拉开距离 = 观众读出抗拒
言语说"我不在乎" + 手指无意识触碰那个物件 = 观众读出在乎
```

## 调用方式

被编剧 Agent 在以下阶段调用：

1. **`/人物`** — OCEAN 卡片 + 依恋类型 + 防御机制 + 需求弧线
2. **`/故事骨架`** — 认知失调设计 + 情境腐蚀设计
3. **`/场景`** — 微表情/身体语言描写 + 认知偏差利用
4. **修改模式** — 行为一致性检查（角色行为是否符合其心理档案）
