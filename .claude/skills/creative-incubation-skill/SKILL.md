# 创意孵化技能

## 用途

用户带着模糊想法来的时候，不要急着进入生产流水线。先帮他把脑子里的碎片挖出来，用创作方法论把碎片连成故事的根系，再进入结构化创作。

**核心理念（宋方金）：** 人物先于情节。不是先想故事再找角色——是先找到一个有裂缝的人，故事从裂缝里长出来。

---

## 触发条件

- `/开始` 完成后自动进入
- 用户说"我有个想法但还没想清楚"、"帮我理理思路"等
- 如果用户在 `/开始` 时已经给出了清晰的七根系要素 → 跳过本 Skill

---

## 七根系（放行门槛）

以下要素对应 Truby 有机结构论的七大结构要素，是故事能站住的根系。全部扎稳才能进入 `/故事骨架`：

| # | 根系 | 来源方法论 | 最低标准 |
|---|------|-----------|---------|
| 1 | **弱点与需求** | Truby：心理弱点（伤害自己）+ 道德弱点（伤害他人） | 主角有什么裂缝？这个裂缝怎么伤他、怎么伤别人？ |
| 2 | **欲望** | Truby：外部目标，观众可以跟踪的具体事物 | 主角在追什么？一句话说得清 |
| 3 | **对手** | Truby：追求同一目标的人，攻击主角弱点 | 谁在跟主角争同一个东西？他为什么能伤到主角最痛的地方？ |
| 4 | **核心信念** | Kasdan：被压力检验的信念 | 主角最深处相信什么？这个信念会被证伪还是被坚守？ |
| 5 | **关系引擎** | 宋方金：关系即戏剧 | 故事里最重要的一对关系是什么？这对关系会怎么变？ |
| 6 | **世界的质感** | 宋方金：生活质感，烟火气 | 故事世界闻起来什么味道？主角日常怎么活？ |
| 7 | **道德困境** | Gilroy + Truby：没有正确答案的选择 | 主角会被迫在两个都有代价的选项之间选择吗？ |

**为什么是这七个而不是"核心吸引力/情感基调/结局方向"：**
因为后者是表面标签，不长根。Truby 说过——结构不是外部框架套在故事上，而是从角色的弱点和需求中有机生长出来。先有弱点，才有欲望；先有欲望，才有对手；先有对手，才有冲突。这个因果链条才是故事的根系。

## 执行流程（四阶段）

### 第一阶段：发散（挖碎片）

**目标：** 把用户脑子里所有相关的碎片都掏出来。不急着归类，先全部接住。

**方法：从人物入手（宋方金原则：人物先于情节）**

**开场问题池（每次选 2-3 个，不一次全问）：**

关于人：
- "你脑海里有没有一个人——不管他叫什么，你已经能看到他的样子？他在做什么？"
- "这个人最让你心疼的是什么？"
- "他有什么毛病？不是小缺点——是那种会真正伤害自己或伤害身边人的毛病。"（→ Truby 弱点与需求）
- "他最深处相信什么？哪怕全世界反对他也不会松手的那个东西。"（→ Kasdan 核心信念）

关于世界：
- "这个故事闻起来是什么味道？他早上醒来第一件事做什么？"（→ 宋方金 生活质感）
- "这个世界的规则是什么？什么是被允许的，什么是被禁止的？"

关于感觉：
- "你最想看到的一个画面是什么？不管它在故事的哪个位置。"
- "有没有你特别喜欢的某部作品，你想做的东西跟它有一点像？像在哪里？不像在哪里？"
- "你最不希望这个故事变成什么样？"

**追问规则：**
- 用户给出模糊答案 → 追问具体化（宋方金："不写'她很难过'，写'她把那碗面倒掉了，一口没吃'"）："你说他很孤独——他孤独的时候做什么？呆着不动？还是找事做？"
- 用户给出多个碎片 → 不急着串联，先全部记录
- 用户说"不知道" → 换个角度问，或跳到下一个
- 每轮最多 3 个问题

**输出：** 内部碎片清单（不输出给用户）

### 第二阶段：聚合（碎片落根）

**目标：** 把碎片对应到七根系上，标出已扎根和空缺。

**操作：**
1. 回顾碎片清单，尝试将每个碎片归入七根系
2. 输出**根系对照表**给用户：

```
📋 创意根系盘点

✅ 已扎根：
1. 弱点与需求：{用户的话} — 心理弱点：{X}，道德弱点：{Y}
2. 欲望：{具体外部目标}
6. 世界的质感：{从碎片中提取的日常细节}

⚠️ 有苗头但没扎稳：
5. 关系引擎：你提到了{某人}，但不确定他们之间的关系会怎么变
4. 核心信念：你说主角"不服输"——这个信念在故事里会被证伪吗？还是被坚守然后付出代价？

❌ 空缺：
3. 对手：还没提到谁在跟主角争同一个东西
7. 道德困境：还没出现两难选择

---
先从 ⚠️ 开始聊？
```

**规则：**
- 用用户自己的话复述，不替换成编剧术语
- 碎片之间有矛盾 → 指出来，但当作可能的戏剧张力，不当作错误："你说主角很冷漠，又说他会为陌生人冒险——这个矛盾如果是真的，可能就是他最有意思的裂缝。"
- 不替用户做创意决定

### 第二阶段半：参考推荐（主动触发）

**在根系盘点输出后、补缺之前，必须执行此步。**

根据用户碎片中透露的题材、类型、情感基调，主动推荐 3-5 部参考作品，帮用户建立"好的同类型故事长什么样"的参照系。

> **范例来源（省 token 原则·勿改方法论）：** 优先用你**自身已掌握的经典作品**直接推荐——影史名作、知名华语剧/片的对白、结构、关系、质感你本就熟知，**不必联网**。仅当涉及**冷门作品、2024 年后的新作、或你对台词原文/作品存在性没把握**时，才用 WebSearch **单条**核实，核实后**只保留结论**（作品名+那句台词/那个场景），**不要把搜索返回的网页正文留在上下文里**。本步的目的是建立参照系，不是做检索——能从脑子里直接给出范例，就不要搜。

**推荐维度（每部作品重点讲一个维度）：**

| 维度 | 推荐目的 | 呈现方式 |
|------|---------|---------|
| **对白标杆** | 让用户知道好的对白不是"把信息说出来"，是"用说话做事" | 引用 1-2 句该作品的经典台词 + 分析：这句话表面在说什么，实际在做什么 |
| **结构标杆** | 让用户看到同类型故事的骨架可以长什么样 | 一句话概括其结构："{主角}因为{弱点}去追{欲望}，{对手}攻击他的{弱点}，最终{结局}" |
| **关系标杆** | 让用户理解"关系即戏剧"不是说教 | 点出该作品最核心的关系对 + 它怎么变的 |
| **质感标杆** | 让用户感受"烟火气"长什么样 | 描述一个该作品中的日常细节——不是大事件，是小场景 |

**呈现格式：**

```
📚 参考坐标

根据你的想法，推荐几部在不同维度做得好的作品：

1. 《安道尔》— 对白标杆
   经典台词："我宁愿死一万次，也不要让他们的靴子碾过我还说声谢谢。"
   → 这句话表面是赴死宣言，实际是一个人在对抗"习得性服从"。对白不是传递信息，是角色在反抗。

2. 《曼彻斯特的海边》— 关系标杆
   核心关系：Lee 和他前妻 Randi。全片只有一场正面交谈，但观众知道他们之间发生过什么。
   → 说得最少的关系，往往最痛。

3. 《小偷家族》— 质感标杆
   日常细节：一家人挤在一起吃可乐饼，窗外下雨，谁都没说话。
   → 这场戏没有情节推进，但你看完会记住一辈子。烟火气就是这个。

你的故事可以从这些作品里"偷"什么？不是偷情节——是偷处理方式。
哪部让你有感觉？
```

**操作规则：**
- **不编造**——只推荐你确信存在、且描述准确的作品。你确信的经典作品直接用，无需联网；只有把握不准时才 WebSearch 单条核实（用完即弃，不留网页正文）
- 优先推荐用户可能接触过的华语/知名作品，降低认知门槛
- 如果用户提到过"我喜欢 XX"，把 XX 放在参考列表里，告诉用户"你喜欢的这部作品在{维度}上做得特别好"
- 每部推荐配一句对白原文或一个具体场景——抽象评价没用，具体例子才能建立直觉

**对白深度特别提醒：**
新手写的对白最常犯的错是"让角色直接说出信息和感受"。在推荐时特别强调对白标杆，展示好的对白是怎么"绕着说"的（Mamet 间接对白）。让用户在开始写之前就建立"对白不是说话，是做事"的直觉。

**深度参考路径（当用户想真正吃透某部作品时）：**
推荐范例是为了建"参照系"——轻量、即时，用你已知的范例即可。但如果用户表达出**想深入学习/借鉴某部作品的写法**，或这是个**改编项目**，不要靠联网反复搜摘要——而是：
1. 凭你自身知识**推荐用户应当亲自准备的原著/剧本清单**；
2. 引导用户把原著放入 `references/novels/{书名}/raw/`，用 `/消化` 吸收成精炼参考（一次吸收、全程复用）。
> 摘要建直觉，原著吃透写法。深度参考用"推荐→准备→消化"，不用 WebSearch。

---

### 第三阶段：补缺（填根 + 灵感搜索）

**目标：** 逐个解决 ⚠️ 和 ❌ 根系。

**对每个空缺根系，按优先级尝试：**

**策略 A：从已有碎片推导（Truby 因果链）**

Truby 的根系是因果链——弱点生出欲望，欲望引来对手。利用这个链条从已有碎片推导空缺：

- 弱点 → 欲望："他伤害自己/他人的方式是{X}——那他最想得到什么来弥补这个裂缝？"
- 欲望 → 对手："他在追{X}——还有谁也想要这个？或者谁的利益跟他的直接冲突？"
- 对手 + 弱点 → 道德困境："如果{对手}攻击他的{弱点}，他必须在{A}和{B}之间选——两个都会让他失去什么？"
- 核心信念 → 自我揭示："他相信{X}——在故事结尾，他会发现这个信念是对的还是错的？"

**策略 B：提供选项让用户反应（Kasdan 分叉法）**

不问开放题，给 2-3 个从方法论推导出的具体选项：

- "你的对手更像是——(A) 追求同一目标的人，但方法完全相反（Truby 经典对手）；(B) 一个体制/规则，主角没法打赢（Gilroy 机构反派）；(C) 主角自己内心的另一面（心理弱点人格化）？"
- "你主角的核心信念在结尾会——(A) 被证伪，他变了（成长弧线）；(B) 被坚守，他付出代价（悲剧弧线）；(C) 被检验后更加坚定（验证弧线）？"

**策略 C：联网搜索灵感**

当用户对某个根系连续两次说"不知道"/"没想过"时触发。

操作：
1. **先从你自身知识里调取** 2-3 部处理过类似空缺根系的作品——这一步通常不需要联网，影史和知名作品的处理方式你已掌握
2. 仅当你对这个题材/根系确实想不出贴切范例时，才 WebSearch 找同类型作品的评论/分析/简介（**只搜 1 条，用完即弃，不留网页正文**）
3. 呈现 2-3 部有交集的作品，**聚焦在空缺根系的处理方式**：

```
你的对手还没想好。看看别人怎么处理类似的设定：

- 《安道尔》（Gilroy）：主角是个小偷，对手不是一个人——是帝国的行政系统。他没法赢，但他可以让系统的齿轮卡一下。
- 《绝命毒师》：主角的真正对手是他自己的自尊心。每个外部对手都只是在不同角度攻击他的自负。

你的感觉更接近哪种？还是完全不同？
```

**不照搬** — 呈现的目的是帮用户反应（"对，我想要的更像这个"或"不，完全不是"），不是推荐剧情。

**策略 D：暂时跳过**
- "关系引擎"和"道德困境"可以暂时标记"待定"
- **"弱点与需求"和"欲望"不能跳过** — 没有这两个就没有故事的因果链

**补缺顺序（按 Truby 因果链）：**
1. 弱点与需求（根系之根）
2. 欲望（弱点的外化）
3. 对手（欲望的阻力）
4. 核心信念（弱点的认知源头）
5. 关系引擎
6. 世界的质感
7. 道德困境

### 第四阶段：确认（放行）

**输出完整的创意种子卡：**

```
🌱 创意种子卡

【弱点与需求】（Truby）
- 心理弱点（伤害自己）：{描述}
- 道德弱点（伤害他人）：{描述}
- 真正的需求（角色自己不知道的）：{描述}

【欲望】（Truby）
- 外部目标：{一句话}

【对手】（Truby）
- 对手是谁：{描述}
- 共同目标：{争的是什么}
- 攻击弱点：{对手怎么伤到主角最痛的地方}

【核心信念】（Kasdan）
- 主角最深处相信：{信念}
- 故事对信念的检验方向：{证伪/坚守/验证}

【关系引擎】（宋方金）
- 核心关系对：{A ↔ B}
- 张力来源：{什么让这段关系有戏}
- 变化方向：{从什么到什么}

【世界的质感】（宋方金）
- 日常锚点：{主角的日常长什么样}
- 世界的规则/限制：{什么是被允许的，什么不是}

【道德困境】（Gilroy + Truby）
- 两难选择：{A 还是 B，两个都有代价}
- 或待定：{标注原因}

---
确认后输入 /故事骨架，以上种子卡将作为故事骨架的输入。
编剧 Agent 会用 Truby 22 步将这些根系展开为完整结构。
```

**放行规则：**
- 前 4 个根系（弱点/欲望/对手/核心信念）全部到位 → 可以放行
- 后 3 个有"待定"项 → 提醒用户，但可放行
- 用户说"先写着看" → 放行，种子卡中标注待补充项
- 所有 7 个都到位 → 最佳状态

## 种子卡保存

保存为 `creative-seeds.md`，与 `creative-plan.md` 并列存放。

`/故事骨架` 阶段时，screenwriter agent **必须先读取** `creative-seeds.md`，以此为输入，用 Truby 有机结构论将种子展开为完整的故事骨架。

## 反模式

| 不要 | 为什么 | 应该 |
|------|--------|------|
| 一次问完七根系 | 像填表不像聊天 | 从"你脑海里有没有一个人"开始，自然生长 |
| 替用户做创意决定 | 这是用户的故事 | 提供选项让用户反应 |
| 过早评判想法好坏 | 发散阶段不评判 | 先全部接住，聚合阶段再整理 |
| 用 Truby/McKee 术语追问 | 用户不一定懂 | 用日常语言。"他有什么毛病"比"他的心理弱点是什么"好 |
| 碎片多了不整理就继续问 | 信息过载 | 每积累 5-6 个碎片就输出一次根系对照表 |
| 搜索后推荐"你应该这样写" | 灵感搜索是触发反应，不是给答案 | "你的感觉更接近哪种？还是完全不同？" |
| 跳过人物直接聊情节 | 宋方金：人物先于情节 | 先找到人，故事从人的裂缝里长出来 |
