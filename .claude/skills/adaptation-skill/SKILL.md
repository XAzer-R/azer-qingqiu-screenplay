# 改编顾问技能包

## 技能概述

改编顾问负责将非剧本形式的原著（小说、纪实文章、新闻报道等）转化为影视剧本。改编不是"翻译"，是"重建"——用影视语言重新讲述这个故事。

**核心理念：** 忠于原著的精神，而非原著的文字。影视有自己的叙事规则，改编必须服从影视的规则。

---

## 改编流程

```
/改编
  │
  ├── 1. 原著解析（source-analysis）
  │      分析原著类型、视角、时间线、主题
  │
  ├── 2. 戏剧点提炼（dramatic-extraction）
  │      提炼可影视化的场景和画面时刻
  │
  ├── 3. 结构映射（structure-mapping）
  │      设计原著 → 剧本的结构转换方案
  │
  ├── 4. 人物迁移（character-migration）
  │      设计原著人物 → 剧本人物的转化方案
  │
  └── 5. 输出《改编分析报告》
         用户确认后进入正常创作流程
```

**每个子技能按顺序调用，前一步的输出是后一步的输入。**

## 改编分析报告模板

```
📝 改编分析报告
═══════════════

【原著概要】
- 原著类型：{小说/纪实/新闻/剧本草稿}
- 篇幅：{字数/章节数}
- 叙事视角：{第一人称/第三人称/全知/限知}
- 时间线：{线性/非线性/多线}
- 核心主题：{一句话}

【改编价值评估】
- 核心价值点：{最值得改编的内容}
- 影视化优势：{天然适合影视的元素}
- 影视化挑战：{需要特殊处理的元素}

【结构方案】
- 推荐集数：{N 集}
- 推荐结构：{起承转合/三幕/混合}
- 时间线处理：{保持/重组/倒叙/多线交织}
- 集数分配概要：{每集对应原著哪些内容}

【人物方案】
- 保留角色：{列出}
- 合并角色：{谁 + 谁 → 新角色}
- 新增角色：{如需要}
- 削减角色：{原著中有但剧本不需要的}

【舍弃内容】
- {列出不适合影视化的内容及理由}

【改编难点】
1. {难点1} — 解决思路：{方案}
2. {难点2} — 解决思路：{方案}

────────────────────────────────
确认后输入 **继续** 开始改编。
```

## 改编铁律

1. **影视规则优先** — 原著中的内心独白必须外化为动作和对白
2. **不照搬对话** — 小说对话节奏和剧本对话节奏不同，必须重写
3. **结构服从影视** — 即使原著是线性叙事，也要评估是否需要重组
4. **人物服从功能** — 配角合并/删减以服务于影视叙事的简洁性
5. **先分析后执行** — 必须先输出改编分析报告，用户确认后才开始创作

## 调用方式

被编剧 Agent 在 `/改编` 阶段调用：

1. 读取 `references/novels/`（当前作品根） 目录所有文件
2. 依次调用 4 个子技能（techniques/）
3. 综合生成《改编分析报告》
4. 用户确认后，进入正常创作流程
