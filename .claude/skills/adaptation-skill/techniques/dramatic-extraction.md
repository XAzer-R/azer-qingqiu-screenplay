# 子技能2：戏剧点提炼

## 功能

从原著中提炼最具戏剧张力的场景和"画面时刻"，评估每个情节点的影视改编价值。

---

## 提炼标准

### 高价值戏剧点

以下特征的情节点优先提炼：

| 特征 | 说明 | 示例 |
|------|------|------|
| **可视化冲突** | 两个人面对面的对抗 | 审讯、谈判、对峙 |
| **不可逆决定** | 角色做了不能撤回的事 | 签字、关门、开枪 |
| **信息揭示** | 改变一切的真相浮出 | 发现秘密、揭穿谎言 |
| **关系断裂/建立** | 两人关系发生质变 | 背叛、告白、决裂 |
| **时间压力** | 倒计时下的选择 | 截止日期、最后通牒 |

### 低价值/需转化的内容

| 原著内容 | 影视化挑战 | 转化方向 |
|---------|-----------|---------|
| 大段内心独白 | 无法直接拍摄 | 外化为动作/对白/他人反应 |
| 抽象思辨 | 缺少画面感 | 转化为具体的道德困境场景 |
| 景物描写 | 无叙事功能 | 保留有叙事功能的环境细节 |
| 时间跳跃 | 观众难以跟随 | 用具体的变化标记时间（白发、季节） |
| 旁白式解释 | 打断画面 | 用场景自身传递信息 |

---

## 提炼流程

### 第一遍：标记

逐章/逐段标记每个情节点：

```
{章节} — {情节概述} — 改编价值：🔴高 / 🟡中 / 🟢低 / ⚫舍弃
标记理由：{为什么是这个评级}
```

### 第二遍：画面时刻

从高价值情节点中提炼"画面时刻"——那些天然具有视觉冲击力的瞬间：

```
画面时刻 #{序号}
原著位置：{章节/页码}
画面描述：{一句话，像镜头描述}
戏剧功能：{这个画面在剧本中能承担什么功能}
```

### 第三遍：内心外化

标记需要外化处理的内心活动段落：

```
外化需求 #{序号}
原著内容：{内心活动原文摘要}
外化方案：{用什么动作/对白/场景来替代}
```

---

## 输出格式

```
戏剧点提炼报告
══════════════

高价值情节点（🔴）：{N} 个
中价值情节点（🟡）：{N} 个
低价值/舍弃（🟢⚫）：{N} 个

核心画面时刻：
1. {画面描述} — 来自 {章节}
2. {画面描述} — 来自 {章节}
...

需外化处理：{N} 处
主要外化方案：{简述}
```
