# 子技能3：结构映射

## 功能

设计原著结构到剧本结构的映射方案——决定原著的内容如何分配到剧本的集数和场景中。

**前置输入：** 原著解析报告 + 戏剧点提炼报告

---

## 映射原则

### 1. 不是平移，是重建

原著的章节划分 ≠ 剧本的集数划分。映射时考虑：

- **每集必须有自己的起承转合** — 不能只是"原著第3-4章"
- **每集必须有开场钩子和结尾钩子** — 重新设计集的边界
- **戏剧密度决定篇幅** — 高密度内容可能占多集，低密度内容可能被压缩

### 2. 时间线重组评估

| 原著时间线 | 建议处理 |
|-----------|---------|
| 线性 | 评估是否需要打乱以制造悬念 |
| 非线性 | 评估是否保持或简化 |
| 多线 | 评估是否收束或保持交织 |
| 平铺直叙 | 强烈建议重组（倒叙/插叙/双线） |

### 3. 集数分配标准

每集应包含：
- 至少 1 个高价值戏剧点
- 至少 1 个关系变化
- 至少 1 个信息揭示
- 完整的微型结构（有起有落）

---

## 映射流程

### 步骤 1：确定总集数

根据原著篇幅和戏剧密度：

```
原著篇幅：{字数}
高价值戏剧点数量：{N}
建议集数：{N} 集
理由：{为什么是这个集数}
单集预估时长：{分钟}
```

### 步骤 2：内容分配

```
集数分配方案
════════════

第1集：
  对应原著：{章节范围}
  核心内容：{一句话}
  起（开场）：{从哪里开始}
  承（推进）：{推进什么}
  转（转折）：{转折点}
  合（收尾）：{结尾钩子}
  高价值戏剧点：{标注}

第2集：
  ...
```

### 步骤 3：新增内容标记

原著中没有但剧本需要的内容：

```
新增内容
════════

位置：第{N}集
内容：{描述}
理由：{为什么需要新增}
类型：{过渡场景/补充冲突/人物深化/视觉化替代}
```

### 步骤 4：删减内容确认

```
删减内容
════════

原著位置：{章节}
内容：{描述}
删减理由：{为什么不适合影视化}
影响评估：{删减后是否影响故事完整性}
补偿方案：{如有影响，如何补偿}
```

---

## 输出格式

```
结构映射方案
════════════

总集数：{N} 集
时间线处理：{保持线性/重组为倒叙/双线交织/...}

集数分配概要：
E01: {核心内容} ← 原著 {章节范围}
E02: {核心内容} ← 原著 {章节范围}
...

新增内容：{N} 处
删减内容：{N} 处

结构映射完整性：✅ 覆盖全部高价值戏剧点 / ⚠️ 有遗漏
```
