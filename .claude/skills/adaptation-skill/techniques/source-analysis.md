# 子技能1：原著解析

## 功能

对 `references/novels/`（当前作品根） 目录中的原著进行系统分析，为后续改编提供基础数据。

---

## 分析维度

### 1. 原著类型识别

| 类型 | 特征 | 改编注意点 |
|------|------|-----------|
| 长篇小说 | 多线叙事、内心描写多 | 需大量删减和外化 |
| 中短篇小说 | 单线为主、意象丰富 | 需扩展和增加人物 |
| 纪实文章 | 事实为基础、无虚构 | 需构建戏剧冲突 |
| 新闻报道 | 信息密集、缺少细节 | 需大量虚构和填充 |
| 剧本草稿 | 已有剧本格式 | 需评估质量和修改方向 |

### 2. 叙事视角分析

- **第一人称** → 改编挑战：如何外化"我"的内心？
  - 解决方案：用动作、对白、其他角色的反应替代
- **第三人称限知** → 改编优势：已有视角限制，易于转化
- **第三人称全知** → 改编挑战：如何选择跟随谁的视角？
  - 解决方案：确定主角，以其视角为主线
- **多视角** → 改编选择：保持多线还是收束为一条主线？

### 3. 时间线梳理

输出时间线图：

```
时间线类型：{线性/非线性/多线/倒叙}

事件序列（按故事内时间排列）：
T1: {事件1} — 原著位置：{章节}
T2: {事件2} — 原著位置：{章节}
T3: {事件3} — 原著位置：{章节}
...

叙事序列（按原著叙述顺序排列）：
S1: {T3} — 倒叙
S2: {T1} — 回到开头
S3: {T2} — 正常推进
...
```

### 4. 核心主题提取

- 原著的核心主题是什么？（用一个动作或场景表达，不用抽象词）
- 这个主题是否适合影视表达？
- 影视化后主题是否需要调整？

---

## 输出格式

```
原著解析报告
════════════

类型：{类型}
篇幅：{字数} / {章节数}
叙事视角：{视角类型} — 改编影响：{简评}
时间线：{类型} — 改编建议：{保持/重组}
核心主题：{一句话}
主题影视化评估：{适合/需调整 + 原因}
```
