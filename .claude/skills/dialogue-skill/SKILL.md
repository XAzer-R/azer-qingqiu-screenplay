# 对白专家技能包 · David Mamet 方法论

以 David Mamet（《拜金一族》《摇尾狗》）为核心方法论蓝本，结合已有的 Kasdan 潜台词体系和 Gilroy 信息克制原则。

**核心理念：** 对白不是表达，是**行动**。角色说每句话都是为了**得到什么**——请求、威胁、拒绝、引诱、逃避。如果一句台词不是一个动作，删掉它。

---

## 一、Mamet 三条铁律

### 铁律1：台词即动作

每句台词必须是角色为达成目标而采取的一个**动作**：

| 台词动作类型 | 示例 |
|-------------|------|
| 请求 | "帮我看一下那个读数。" |
| 威胁 | "你有三十秒。" |
| 拒绝 | "不。" |
| 引诱 | "那个矿带我留了一半给你。" |
| 逃避 | "你问这个干什么？" |
| 试探 | "你的船是什么型号？" |
| 伪装 | "我没事。"（实际不是没事） |

**检查方法：** 能不能在每句台词前面加一个动词？"他**威胁**说：'你有三十秒。'" 如果加不上动词，这句台词没有功能。

### 铁律2：删掉所有"漂亮"的台词

如果一句台词让你觉得"写得真好"，它很可能是作者在炫技。角色不会说漂亮话——他们只想达到目的。

```
❌ "在这片星云的尽头，或许我们能找到属于自己的黎明。"
✅ "还有十二跳。"
```

### 铁律3：不写情绪词

不写"他愤怒地说"。只写他说了什么、做了什么。观众自己判断。

```
❌ 角色甲冷冷地说："你走吧。"
✅ 角色甲看着扫描仪。"你走吧。" 她没有抬头。
```

## 二、间接对白理论

**Mamet 核心技术：** 角色越想要一样东西，越不会直接提到它。

### 间接对白三层设计

| 层 | 内容 | 功能 |
|----|------|------|
| **话题层** | 两人在谈论什么话题 | 表面内容 |
| **策略层** | 角色用什么策略获取想要的东西 | 台词动作 |
| **欲望层** | 角色真正想要什么 | 从不直接说出 |

**示例：**
```
话题层：他们在讨论矿带的分配
策略层：角色乙在用沉默施压，角色甲在用数据反驳
欲望层：角色乙想知道角色甲是否信任他；角色甲想证明自己不需要任何人
```

### 间接对白的禁忌

- ❌ 角色直接说出自己想要什么："我需要你信任我。"
- ❌ 角色解释自己的策略："我之所以这样说是因为..."
- ❌ 角色承认自己的真实感受："说实话，我害怕。"

## 三、节拍（Beat）理论

对白不是句子的堆叠，而是**节拍**的序列。

### 节拍的定义

一个节拍 = 一次"想要 → 尝试 → 受阻"的微型单元。

当一个节拍结束（尝试失败），角色**换策略**，进入下一个节拍。

### 节拍分析模板

```
{场景号} 对白节拍分析
═══════════════════

节拍1：{角色A} 策略：礼貌请求 → {角色B} 反应：拒绝
节拍2：{角色A} 策略：引诱/交换 → {角色B} 反应：犹豫
节拍3：{角色A} 策略：威胁 → {角色B} 反应：沉默
节拍4：{角色B} 策略：反击 → {角色A} 反应：退让

节拍转换检查：每次策略变化是否有触发原因？
```

### 策略升级规则

角色不会重复使用失败的策略。每次受阻后策略升级：

```
礼貌请求 → 诱惑 → 施压 → 威胁 → 沉默（最强策略）
```

## 四、省略美学

Mamet 的台词以极简著称。

### 权力编码

- **句子越短，权力越大。**
  - 指挥官："撤。"（一个字=绝对权力）
  - 新手："我觉得也许我们应该考虑撤退？"（长句=没有权力）

- **省略越多，角色越强。**
  - 老手之间不互相解释：两个老兵不说"我们需要让他们先进来，然后从侧翼包抄"——他们只需要一个眼神。
  - 解释越多，角色越弱或越不信任对方。

### 台词精简对照表

| 病症 | 原文 | Mamet 版 |
|------|------|---------|
| 完整句 | "我认为我们应该现在离开这里。" | "走。" |
| 礼貌用语 | "可以请你帮我检查一下护盾吗？" | "护盾。" |
| 重复确认 | "所以你是说，他们已经来了？" | 删掉。直接写下一个动作。 |
| 自我解释 | "我之所以不同意，是因为..." | "不行。" |

## 五、沉默设计（Mamet + Pinter）

### 三种停顿（Mamet 区分）

| 类型 | 定义 | 剧本写法 | 功能 |
|------|------|---------|------|
| **Beat** | 节拍转换，策略切换 | （停顿。） | 角色在换策略 |
| **Pause** | 角色在处理信息 | （沉默。） | 角色在思考/感受 |
| **Silence** | 关系在变化 | 两人都没有说话。 | 关系发生了不可逆改变 |

### 沉默密度标准

- 高张力场景：沉默应该比台词多
- 日常场景：台词可以多于沉默
- 转折时刻：关键决定前必须有 Silence
- 战斗结束后：至少 3 秒的纯环境音

## 七、对白病症诊断

### 六种病症（保留原有）+ Mamet 新增

| 病症 | 症状 | Mamet 修复 |
|------|------|-----------|
| 解释动机 | "我这样做是因为..." | 删掉。用动作表达。 |
| 描述情绪 | "我现在很愤怒" | 删掉。写一个具体动作。 |
| 总结剧情 | "所以你的意思是..." | 删掉。直接推进。 |
| 哲学宣言 | "人生就是这样..." | 删掉。用一个选择表达。 |
| 过于顺畅 | A问B答，完美配合 | 加入节拍转换：打断、回避、误解 |
| 信息倾倒 | 一句话多个信息 | 拆分到多场景，分层传递 |
| **策略固定** | 角色全程用同一策略说话 | 每次受阻后必须换策略 |
| **作者炫技** | "漂亮"的台词 | 删掉。角色不说漂亮话。 |

## 调用方式

被编剧 Agent 在以下阶段调用：

1. **`/人物`** — 建立角色语言档案（含 Mamet 维度）
2. **`/场景`** — 对白创作（节拍设计 + 间接对白三层 + 省略美学）
3. **修改模式** — 对白病症诊断 + 节拍分析 + 台词精简
