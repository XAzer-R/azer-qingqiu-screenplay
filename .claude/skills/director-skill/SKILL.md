# 导演视角技能包

## 技能概述

本技能包为审查员提供导演维度的审查能力。导演视角关注的不是"写了什么"，而是"观众会看到什么、感受到什么"。

**核心理念：** 剧本是蓝图，导演视角审查这个蓝图是否能被有效地转化为视听体验。

---

## 一、视觉叙事审查

### 画面感检查

每个场景描述是否能在脑海中形成清晰画面：
- [ ] 有具体的视觉锚点（不是泛泛的"一个房间"，而是有细节的空间）
- [ ] 关键时刻有视觉焦点（观众的目光被引向哪里）
- [ ] 用画面传递了信息（不依赖对白解释）

### 视觉叙事层次

| 层次 | 检查点 | 示例 |
|------|--------|------|
| **前景** | 角色的动作和表情是否具体 | "她把杯子转了半圈" vs "她很紧张" |
| **中景** | 人物之间的空间关系是否有意义 | 两人之间放着一张桌子 = 距离感 |
| **背景** | 环境是否参与叙事 | 窗外的雨 ≠ 装饰，= 情绪底色 |

### 常见问题
- ❌ 场景描述只有对白，缺少视觉元素
- ❌ 关键情绪时刻没有视觉承载
- ❌ 环境描写是装饰性的，不参与叙事

## 二、节奏把控审查

### 全集节奏检查

一集好的剧本应该有清晰的节奏变化：

```
高张力 ─────╲
             ╲──── 呼吸点（让观众消化）
                   ╱────── 新的张力建立
          高张力 ─╱
                  ╲──── 高潮
```

### 节奏要素

| 要素 | 检查点 |
|------|--------|
| **加速** | 短句、快速切换、动作密集 — 是否在正确的位置使用？ |
| **减速** | 长描述、沉默、细节特写 — 是否给了观众呼吸空间？ |
| **停顿** | 关键信息后是否有停顿让观众消化？ |
| **对比** | 安静场景后是否跟高张力场景？反之亦然？ |

### 节奏病症
- ❌ **全程高压**：没有呼吸点，观众疲劳
- ❌ **全程平淡**：没有张力峰值，观众走神
- ❌ **错位高潮**：高潮放在了错误的位置
- ❌ **拖沓收尾**：高潮后还有大量内容

## 三、镜头语言审查

### 镜头暗示检查

剧本不写导演说明，但好的剧本暗示了镜头语言：

| 写法 | 暗示的镜头 |
|------|-----------|
| "整个车间只有她一个人" | 大全景 → 孤独感 |
| "她的手指在桌面上敲了两下" | 特写 → 紧张/等待 |
| "他走过长长的走廊" | 跟拍/推轨 → 压迫感 |
| "两人隔着桌子对视" | 正反打 → 对峙感 |
| "窗外的城市灯火" | 空镜 → 转场/情绪过渡 |

### 检查点
- [ ] 关键情绪时刻是否有适合特写的细节描写
- [ ] 空间转换是否自然（不是突然跳到新场景）
- [ ] 是否有可以作为空镜/转场的视觉元素

---

## 四、空间调度审查

### 空间权力关系

人物在空间中的位置反映权力关系和心理状态：

| 空间元素 | 叙事含义 |
|---------|---------|
| 谁坐谁站 | 权力高低 |
| 谁先动 | 谁更急切/弱势 |
| 两人距离 | 关系远近 |
| 谁占据中心位置 | 谁主导场景 |
| 谁靠近出口 | 谁想逃离 |

### 检查点
- [ ] 空间描述是否暗示了人物关系
- [ ] 人物的移动是否有目的（不是随意走动）
- [ ] 空间变化是否反映情节发展

## 五、情绪曲线审查

### 全集情绪走向

好的剧本有清晰的情绪曲线——不是直线上升或直线下降，而是有起伏的波形：

```
情绪强度
  │
  │     ╱╲        ╱╲╲
  │    ╱  ╲      ╱   ╲╲
  │   ╱    ╲    ╱     ╲╲  ← 高潮
  │  ╱      ╲  ╱       ╲
  │ ╱        ╲╱         ╲─── 结尾余味
  │╱
  └──────────────────────── 时间
    开场   中段    转折   收尾
```

### 情绪曲线检查点
- [ ] 开场是否建立了情绪基调
- [ ] 是否有至少一次情绪转折（从正到负或从负到正）
- [ ] 高潮时刻是否是全集情绪最强的点
- [ ] 结尾是否留有余味（不是情绪归零）

### 情绪曲线病症
- ❌ **情绪平线**：全集情绪没有变化
- ❌ **情绪断裂**：相邻场景情绪跳跃过大，没有过渡
- ❌ **高潮提前**：最强情绪出现在中段，后面无法超越
- ❌ **情绪泄漏**：高潮后用对白解释情绪，消解了积累的力量

## 六、视听语言武器库

本武器库供审查时参照——剧本是否暗示了有效的视听手法？也供编剧创作时选用。

### 镜头语言类

| 手法 | 效果 | 适合场景 |
|------|------|---------|
| **一镜到底** | 真实感、沉浸感、时间不可逆 | 需要"在场感"的段落 |
| **固定机位时间流逝** | 变与不变的对比 | 时间跨度大的段落（一个空间的四季更替） |
| **连续推轨/Dolly** | 空间的揭示，不断发现新信息 | 空间本身承载信息（从豪宅推到贫民窟） |
| **第一人称POV** | 极端代入感，限制信息 | 视角置换、"身临其境"的段落 |
| **微距/显微镜头** | 熟悉事物变陌生 | 尺度跳跃、质感特写 |

### 剪辑/时间类

| 手法 | 效果 | 适合场景 |
|------|------|---------|
| **跳切蒙太奇** | 时间压缩、重复的荒诞感 | "日复一日"、快速推演后果 |
| **分屏** | 对比、并置、平行时间线 | 双线并置、recap、对比两个空间 |
| **交叉剪辑** | 对比加速、张力累积 | 两条看似无关的线最终关联 |
| **倒放** | 熟悉动作变陌生、因果倒置 | 时间操作、循环结构 |
| **定格** | 强制注意、悬念标点 | 翻转瞬间、关键细节强调 |

### 画面构成类

| 手法 | 效果 | 适合场景 |
|------|------|---------|
| **对称构图** | 秩序感、仪式感、压迫感 | 制度化、规则化的场景 |
| **前景/背景双层叙事** | 同一画面内两层信息 | 不分屏但需要并置的段落 |
| **色彩限制** | 视觉"规则感"，颜色成为叙事元素 | 颜色与概念有直接关联时 |

### 声音类

| 手法 | 效果 | 适合场景 |
|------|------|---------|
| **画面与声音错位** | 两层信息碰撞、讽刺反差 | 画面和平+声音灾难，或反之 |
| **环境音放大** | 日常变得不安、异常 | 需要"日常中的恐怖感"的段落 |
| **静默** | 迫使注意力集中、真空感 | 高密度信息流后突然安静——沉默即高潮 |

### 界面/媒介类

| 手法 | 效果 | 适合场景 |
|------|------|---------|
| **屏幕录制** | 极致当代感、偷窥感 | 聊天记录、搜索、通知驱动的段落 |
| **伪纪录片** | 真实外壳包裹荒诞内核 | 需要"严肃"的壳来反衬的段落 |
| **数据可视化** | 冷静数字背后的巨大悲剧 | 用"客观感"制造反差 |

### 视听语言审查检查点

- [ ] 关键场景是否暗示了适当的视听手法？
- [ ] 视听手法是否与内容匹配——形式是否强化了内容？
- [ ] 同一种手法是否过度使用（全片同一种炫技就不再特别）？
- [ ] 是否有至少一处视听手法的"递进"或"打破"（从固定变移动、从彩色变黑白）？

## 七、导演审查输出模板

```
【导演备注】

视觉叙事：
- {具体场景号}：{评价 + 改进建议}

节奏把控：
- 整体节奏评价：{快/慢/有变化/单调}
- 问题位置：{具体场景号} — {问题描述}

空间调度：
- {具体场景号}：{空间安排的叙事效果评价}

情绪曲线：
- 曲线走向：{描述}
- 问题位置：{具体场景号} — {情绪处理问题}
```
