# 日常叙事分析

本包借鉴 Paul Schrader 的日常、落差与静止框架，由作者整理为方法提示；不是理论原著摘录或官方工具。

只在用户选择观察性、克制或日常化叙事时加载。它不能覆盖用户已经确定的角色动机与因果。

1. 用当前作品实际作息建立时间感，不预设城市、职业、债务或人生目标。
2. 用动作、物件、空间和停顿呈现人物与环境的落差，不让旁白重复画面。
3. 偶遇可以组织场景，但不能替代需要明确因果的戏剧事件。
4. 静止表现理解发生变化，不要求每场戏都完整走完三个阶段。
5. 是否使用日记、访谈或自拍视频，由作品需求决定，不指定既有主人公或场所。
6. 审稿时说明本包带来的效果和代价，不能因为作品不是这一风格就判失败。

输出当前场景的结构建议；没有提供项目输入时只解释方法，不生成具体故事。
