# 严肃叙事风格约束

## 风格核心哲学

**"观众比角色先感受到。"**

不告诉观众角色的情绪，让观众自己感受到，比角色先感受到。
当角色还在压抑时，观众已经替他们难过了。
这就是严肃叙事的张力来源。

---

## 六条铁律

### 铁律1：永远不写内心活动
写她做了什么，不写她想了什么。

```
❌ "她想到了她的母亲。"
✅ "她的手在'黎明'两个字上停了一下。"

❌ "他心里很复杂。"
✅ "他把那份文件翻到最后一页，又翻回来。"
```

### 铁律2：永远不解释动作的含义
动作自己会说话，不要在旁白里解释它意味着什么。

```
❌ "角色乙掰了一块肉干递过去——这是他接受一个人的方式。"
✅ "角色乙掰了一块肉干递过去。角色丙接了。"

❌ "她没有回头，因为她知道如果回头就会留下来。"
✅ "她没有回头。"
```

### 铁律3：用物体代替情感词
找到情绪的物理载体。

```
❌ "她很紧张。"
✅ "杯底在桌面上划了一下。"

❌ "他很愤怒但在压抑。"
✅ "他把文件放下。没有摔。"

❌ "她悲伤极了。"
✅ "她把照片翻过去，正面朝下。"
```

### 铁律4：让沉默做功
不解释沉默，不告诉观众沉默里包含了什么。

```
❌ "这段沉默里包含了很多他们说不出口的话。"
✅ "沉默。"

❌ "两人陷入了沉默，谁都知道这个问题没有答案。"
✅ "没有人说话。"
```

### 铁律5：细节必须具体
有材质、颜色、声音、气味——可以被感知的细节。

```
❌ "一种食物"
✅ "加达里压缩营养块，灰色，方形，化学蛋白质的味道"

❌ "房间里很冷"
✅ "冷凝管里有水珠在往下走"

❌ "机器轰鸣"
✅ "电容器的充放电声，三秒一次，像一个老人的呼吸"
```

### 铁律6：结尾必须开放
不解释这场戏意味着什么，不给情绪一个出口。

```
❌ "她终于哭了，所有的委屈都在这一刻爆发出来。"
✅ "她坐在那里，没有动。"

❌ "他意识到，一切都结束了。"
✅ "他把灯关了。"
```

## 对白风格约束

### 极简对白
严肃叙事的对白是压缩过的，每句话都在负重。

- 少说，把没说出来的比说出来的更重要
- 没有废话，没有闲聊，除非闲聊本身是一种掩盖
- 沉默比台词多

### 拒绝"剧本腔"
不写宣言式台词，不写解释式台词。

```
❌ "我们必须团结，只有在一起才能对抗这一切。"
✅ "第一波不是赢。是让他们把主力投进来。"

❌ "你知道我一直都在这里，对吗？"
✅ "你吃了吗？"（深层：我在这里。）
```

### 信息分层
角色说A，其实在说B。

```
表层："你的船是什么型号？"
深层：我在评估你值不值得信任。
```

## 节奏约束

### 慢镜头时刻
严肃叙事的高潮不是爆炸，是一个细节。

最重要的时刻，节奏应该变慢，不是变快：
- 用更多空间描写一个动作
- 让时间在那一刻拉伸
- 观众在那一刻才意识到这件事有多重

### 情绪延迟
不在情绪的发生时刻写情绪，写情绪的后果。

```
❌ 她听到消息，悲痛欲绝。（发生时刻）
✅ 三天后，她还是把那个联系方式留在手机里，没有删。（后果）
```

## 环境描写约束

### 环境有叙事功能
每个空间都说明角色的处境或心理。

- 拒绝装饰性描写（美丽的星空、壮观的战场）
- 环境细节必须和角色状态有关联
- 一个具体的声音/气味/光线，胜过一段全景描写

### 具体化原则
```
❌ "战场一片废墟"
✅ "有一艘驱逐舰的舰桥还没有完全沉下去，灯还亮着。"

❌ "宇宙深处，星光闪烁"
✅ "通讯频道里只有静电噪声。"
```
