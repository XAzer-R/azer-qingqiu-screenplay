# 剧集扩展工具包

本格式包不替代现有的剧集创作系统（structuralist-skill 的轨道编织 + reviewer 的评分体系），而是补充一套**管理工具**——解决长线剧集创作中的连续性、预算控制和节奏管理问题。

---

## 一、连续性管理系统（四张追踪表）

每写完一集，立即更新以下四张表。开始写新一集前，先查阅确认当前状态。

### A. 角色状态追踪

```
角色 | 本集结束时的状态 | 关键变化 | 下集需延续的点
-----|----------------|---------|---------------
[名] | [物理/情感/关系状态] | [本集发生的变化] | [下集必须回应的点]
```

### B. 暗线进度追踪

```
暗线名称 | 当前进度 | 本集推进内容 | 下次推进计划（哪集）
---------|---------|------------|------------------
[暗线1] | [进度描述] | [本集做了什么] | E[X]
```

**暗线规则：**
- 暗线不能在每集都推进——那就不是"暗"线了
- 暗线的暗示应隐藏在"表面上有别的含义"的场景中
- 暗线浮出水面时应改变观众对前面多集内容的理解
- 整季 1-3 条暗线，每条有明确起点和终点

### C. 埋种/回调登记

```
种子内容 | 埋入集数 | 场景 | 计划回调集数 | 回调方式 | 已回调？
---------|---------|------|------------|---------|-------
[种子] | E[X] | [场景号] | E[Y] | [如何回扣] | ✅/❌
```

**伏笔密度建议：**
- 每集至少 1 个集内伏笔
- 每 3 集至少 1 个短程伏笔在回扣
- 整季至少 2-3 个长程伏笔（跨5集以上）
- 至少 1 个季度伏笔（第1-2集埋、季终回扣）

### D. 已公开信息清单

```
信息内容 | 公开集数 | 公开方式 | 谁知道（角色层面）| 谁不知道
---------|---------|---------|----------------|--------
[信息] | E[X] | [展示/暗示] | [角色列表] | [角色列表]
```

**使用纪律：**
- 每集完成后立即更新四张表
- 开始新集前先查阅
- 发现连续性冲突时，优先修改新集内容，而非改已定稿

## 二、弧光预算分配

弧光不能随意在各集发生——需要规划每集的"变化额度"。

### 弧光预算表模板

```
角色：[名字]
季度弧光：从[A状态] → 到[B状态]
Lie：[角色相信的谎言]
总集数：N

集  | 弧光事件 | 变化方向 | 变化幅度 | 累计进度
----|---------|---------|---------|--------
E1  | [事件] | Lie被强化 | 微弱 | 0%
E2  | [事件] | 第一次质疑 | 小 | 5%
... | ... | ... | ... | ...
E[N]| [事件] | 关键选择→新常态 | 完成 | 100%
```

### 预算规则（按总集数 N 自适应）

- 前 25% 集数：累计进度不超过 15%
- 至少 1 次伪变化后的回退（通常在 40%-60% 位置）
- 65%-85% 位置是加速区——变化量最大
- 不是每集都需要弧光事件——有些集角色不变化也可以

## 三、世界观信息释放时间表

```
信息层 | 内容 | 释放位置（按比例） | 释放方式
------|------|-------------------|--------
表层规则 | [世界基本运行方式] | 前10-15%（E1-E2区间） | 直接展示
表层细节 | [规则的有趣延伸] | 15-30% | 角色遭遇 / B Plot
运行逻辑 | [为什么世界是这样] | 40-55% | 角色调查/发现
逻辑延伸 | [逻辑的更深层含义] | 55-75% | 关系对话中泄露
底层真相 | [世界的终极真相] | 最后20% | 高潮揭示
伏笔回扣 | [前面细节获新含义] | 最后1-2集 | 观众恍然大悟
```

**原则：**
- 每层信息释放前需至少 1-2 集铺垫
- 通过角色行动和发现呈现，不通过旁白或字幕
- 释放新信息时必须改变观众对已知信息的理解
- 同一集不要释放太多新信息——每集最多一个新层

## 四、集间节奏管理

### 十种情绪基调类型

每集从以下选择一个主导情绪（可混合，但应有明确主导）：

| 类型 | 功能 | 位置建议 |
|------|------|---------|
| **建置型** | 观众适应世界、认识角色 | 开头几集 |
| **轻快型** | 喜剧感、角色互动、积累好感 | 紧张集后 |
| **紧张型** | 核心冲突升级、压力增大 | 发展段 |
| **呼吸型** | 节奏放缓、关系深化、情感锚点 | 高强度后 |
| **转折型** | 大事件发生、格局改变 | 季度中段 |
| **压力型** | 内外压力持续收紧 | 危机段 |
| **崩塌型** | 一切尽失、最低点 | 第三阶段 |
| **至暗型** | 角色直面 Ghost 和 Lie | 崩塌后 |
| **反击型** | 角色带着新认知反击 | 高潮前 |
| **高潮型** | 季度核心冲突的解决 | 最后 |

### 节奏波浪原则

- 不能连续 3 集以上同一基调
- 紧张/压力集之后需至少 1 集呼吸或轻快
- 崩塌和至暗可以连续（构成"低谷"），但前后必须有对比
- 呼吸集不是废集——用来深化角色关系、推进 B Plot

### 参考节奏模板（按总集数比例）

```
前10%:   建置
10-20%:  轻快/建置
20-30%:  第一次紧张
30-40%:  呼吸
40-50%:  转折（中段大事件）
50-60%:  过渡+升级
60-70%:  压力
70-75%:  呼吸或伪高潮
75-85%:  崩塌/至暗
85-95%:  反击
最后5-10%: 高潮+落幕
```

### 集间双轨检查

除了情绪基调，还应检查：
- 相邻两集的平均情节强度是否有对比——不能连续几集都是高强度
- 相邻两集的平均情感强度是否有对比——不能连续几集都是重情感
- 季度中段的"呼吸集"是否真的在"呼吸"——情节和情感都需要降下来

## 五、分集大纲模板（增强版）

在现有分集大纲基础上，增加以下字段：

```
第[X]集《集名》

【集内核心】
  一句话故事（本集Logline）：
  本集核心戏剧动作：目标 → 阻碍 → 结果
  本集情绪基调：（从十种类型中选）

【集内结构概要】（含时长预算和双轨节奏）
  冷开场/开场钩子（约X秒）：
  建置（约X分钟）：情节：松/中/紧 | 情感：轻/中/重
  发展（约X分钟）：情节：松/中/紧 | 情感：轻/中/重
  高潮（约X分钟）：情节：松/中/紧 | 情感：轻/中/重
  结局 + 集末钩子（约X分钟）：情节：松/中/紧 | 情感：轻/中/重

【季度连接】
  弧光预算消耗：本集角色变化了什么？累计进度到多少？
  暗线推进：本集推进了哪条暗线？
  世界观释放：本集是否释放了新信息层？
  埋种/回调：本集埋了什么？回收了什么？

【集间关系】
  承接上集：从什么状态开始？
  递交下集：结束时留了什么？
  与前后集的节奏对比：情节强度？情感强度？
```

## 剧集常见陷阱

- 跳过分集大纲直接写单集 → 必须先拉通全季再动笔
- 为季度弧线牺牲单集精彩度 → 每集拆出来都要好看
- 弧光预算失控（前面变化太大，后面无处可去）→ 严格预算
- 连续性错误 → 每集开写前查追踪表
- 集末钩子过于强行 → 钩子是本集故事的自然延伸
- Running Subplot 太多 → 同时运行的不超过 3 条
- 连续几集高强度 → 用集间双轨检查
- 伏笔埋了忘记回扣 → 用登记表逐条审计
