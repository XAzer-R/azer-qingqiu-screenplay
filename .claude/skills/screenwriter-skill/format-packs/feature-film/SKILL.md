# 电影长片格式包（75-120分钟）

## 核心特征

- **时长**：75-120分钟
- **角色**：主角有完整的 Ghost/Lie/Flaw/Want/Need，配角承载 B-Story
- **结构**：根据题材选择结构方法论
- **弧光**：多次伪变化后的真正转变
- **世界观**：可复杂，分层展示
- **节奏**：需要"呼吸感"——张弛交替，不能持续高密度

## 长片与短片的关键差异

- 短片是冲刺，长片是马拉松——需要安静场景让观众消化情绪
- 短片讲一个事件，长片讲一个旅程——一系列递进的考验
- 短片的潜台词在对白中，长片的潜台词还在场景序列中——两个场景的并置本身就是潜台词

## 人物深度设计（长片级）

在 screenwriter-skill 的 Want/Need/Arc 基础上增加三个维度：

### Ghost（前史创伤）
角色过去的某个事件，塑造了当前世界观和行为模式。可以只通过反应被暗示。

### Lie（角色相信的谎言）
因 Ghost 而形成的错误信念。Lie 驱动着 Want。
- Ghost是"被信任的人背叛" → Lie是"不能信任任何人" → Want是"独自完成任务"

### Flaw（性格缺陷）
Lie 在行为层面的外化。角色不断伤害自己和他人的行为模式。

**完整弧光链条：**
Ghost → Lie → Flaw → Want（错误追求）→ 一系列考验 → 面对 Need → 关键选择（坚持 Lie 还是拥抱 Need）→ 新常态

## 结构选型指南

| 题材/意图 | 推荐方法论 | 原因 |
|----------|-----------|------|
| 商业类型片 | **Save the Cat 15节拍** | 节拍精确到分钟，适合严格节奏控制 |
| 成长/冒险/变形记 | **Dan Harmon Story Circle** | 八步圆环天然适合"离家→历险→回归" |
| 角色复杂度高、主题先行 | **McKee 故事原理** | 以价值转变为核心，适合深度戏剧 |
| 角色驱动型文艺片 | **内在节拍表** | 节拍是内心状态转变而非外部事件 |
| 混合型/不确定 | 先问用户，默认 Story Circle | 足够通用且容易理解 |

## 结构模板A：Save the Cat 15节拍

适用于：类型片、高概念商业片。核心逻辑：每个节拍有精确时间窗口。

```
第一幕（约25分钟）
1. Opening Image — 角色的"旧世界"，与 Final Image 对照
2. Theme Stated（约第5分钟）— 某人无意间说出主题，主角此时不理解
3. Set-Up（1-10分钟）— 展示日常、缺陷、世界
4. Catalyst（约第12分钟）— 打破平衡的不可逆事件
5. Debate（12-25分钟）— 主角面对变化的犹豫

第二幕前半（约30分钟）
6. Break into Two（约第25分钟）— 主角主动选择进入"新世界"
7. B Story — 新关系，承载主题论点
8. Fun and Games（30-55分钟）— 预告片段落，主角在新世界试错
9. Midpoint（约第55分钟）— A/B Plot 交汇，伪胜利或伪失败

第二幕后半（约30分钟）
10. Bad Guys Close In（55-75分钟）— 内外压力收紧
11. All Is Lost（约第75分钟）— 最低点，死亡气息
12. Dark Night of the Soul（75-85分钟）— 直面 Lie 和 Ghost

第三幕（约15分钟）
13. Break into Three（约第85分钟）— 用全新方式应对
14. Finale（85-105分钟）— 五步高潮法
15. Final Image — 与 Opening Image 对照，新常态
```

## 结构模板B：Dan Harmon Story Circle

适用于：成长故事、冒险故事、角色内外旅程同步推进。

```
1. YOU — 角色在舒适区
2. NEED — 角色产生欲望
3. GO — 进入不熟悉的处境（不可逆）
4. SEARCH — 寻找、适应、挣扎
5. FIND — 得到了想要的东西
6. TAKE — 为所得之物付出代价（圆环底部）
7. RETURN — 回到熟悉的处境
8. CHANGE — 角色已经改变
```

前四步和后四步互为镜像。特别适合角色旅程和变形故事。

## 结构模板C：McKee 故事原理

适用于：角色复杂度高的剧情片、主题先行的作品。

```
一、控制性理念 — 全片一句话主题判断：[价值] + [原因]
二、价值转变 — 每场景核心价值必须翻转（正→负或负→正）
三、鸿沟 — 角色期望的结果 vs 实际结果的落差，层层加深
四、激励事件 — 打破平衡，创造全片核心问题
五、进展纠葛 — 冲突逐步升级，内心困境同步深化
六、危机选择 — 不可逆的两难（两害/两善取舍）
七、高潮 — 危机选择的行动化，不可逆
八、结局 — 新秩序，控制性理念获得证实或证伪
```

**McKee 自检：**
- [ ] 每个场景都有价值转变？
- [ ] 鸿沟逐步加深？
- [ ] 危机选择是真正的两难？

## 结构模板D：文艺片内在节拍表

适用于：角色驱动型、不依赖强情节的作品。

```
1. 常态与裂缝 — 日常生活中某个细节暗示表面之下的不安
2. 扰动 — 一个小事件让角色无法继续假装正常
3. 游走与回避 — 裂缝已出现但角色试图回避
4. 对峙 — 被迫面对一直回避的东西
5. 选择或接受 — 接受痛苦的真相，或决定继续活在谎言中
6. 余震 — 结局不是答案，是一个新的问题
```

### 五种风格变体

可叠加在内在节拍表上，调整每一步的"质感"：

**变体1：是枝裕和式（日常流）**
- 建置极慢，前30分钟几乎全是日常。没有明确激励事件
- 对峙不是正面冲突，是某个平淡瞬间里突然泄漏的情绪
- 结局留在极其日常的动作上。节奏像呼吸——均匀、缓慢

**变体2：王家卫式（情绪流）**
- 叙事不追求因果，场景连接是情绪而非逻辑
- 大量重复的视觉母题。旁白和画面之间有错位
- 时间是主角——跳跃的时间线、过期的日期

**变体3：小津安二郎式（静物流）**
- 极低机位，固定镜头。"枕镜头"制造停顿让情绪沉淀
- 冲突来自代际间无法弥合的理解鸿沟
- 结局是一种安静的"接受"

**变体4：Richard Linklater式（对话流）**
- 几乎全靠对话推进，对话就是故事本身
- 高潮就是一句对了的话。结局通常开放

**变体5：奉俊昊式（类型杂交）**
- 骨架是严格的商业片结构，但皮肤下塞入社会批判和黑色幽默
- 前半和后半可以是完全不同的类型
- 空间即隐喻——角色的物理位置对应社会位置

## Subplot 交织

长片通常 2-3 条故事线同时运行：
- **A Plot**：主角外在旅程——追求 Want、面对阻碍
- **B Plot**：通常是一段关系，承载主题论点
- **C Plot（可选）**：节奏调剂，或从另一角度映射主题

**交织原则：** A/B 在 Midpoint 交汇；B 线进展映照 A 线；所有线最终服务主角弧光。

## 伏笔与回扣系统

**伏笔层次：**
- **道具伏笔**：物件从日常变关键
- **台词伏笔**：闲聊在后段获得全新含义
- **行为伏笔**：习惯性动作暗示 Ghost
- **结构伏笔**：看似无关的场景被证明是关键信息

**伏笔登记表：**
```
伏笔内容 | 层次 | 首次出现位置 | 回扣位置 | 回扣方式
---------|------|------------|---------|--------
```

长片至少 3-5 个伏笔/回扣对。埋下时不能太刻意，每个都必须有回扣。

## 暗线设计

暗线是隐藏在水面下的故事线——通过伏笔、细节、不经意的对白运行，直到某个时刻浮出水面。

- 先确定暗线终点 → 反向推导需要多少暗示
- 每个暗示都必须有表面含义（第一次看是表面，第二次看是暗线）
- 长片 1-2 条暗线

---

## 世界观分层展示

```
表层规则（前30分钟展示）
  "这个世界的基本运行方式是什么"

运行逻辑（第二幕展示）
  "为什么这个世界是这样的"

底层真相（高潮段揭示）
  "这个世界真正的面目是什么"
```

每层揭示通过角色行动和发现呈现，不通过旁白或字幕。

## 次要角色设计

每个有台词的角色都应有功能性理由：

| 功能 | 定义 |
|------|------|
| **镜像角色** | 映射主角某个侧面，走了主角没走的路 |
| **催化角色** | 推动主角变化的外力（导师/诱惑者/挑战者） |
| **主题角色** | 具象化主题论点的某个立场 |
| **节奏角色** | 喜剧 relief、情绪调剂 |

每个至少承担一个功能，最好两个。没有功能的角色应合并或删除。

## 长片常见陷阱

- 第二幕松垮 → 确保 Midpoint 足够强
- 弧光太线性 → 至少一次伪变化后回退
- B Story 脱节 → B Story 必须映射主题
- 高潮只是"更大的打斗" → 高潮是角色内心选择的外化
- 世界观一次性倾倒 → 分层释放
- 伏笔过于刻意 → 首次出现必须有合理表面理由
- 全片节奏单调 → 用双轨节奏检查起伏
- 情节和情感始终同步 → 制造错位

## 与现有技能包的关系

- 结构设计主线仍用 `structuralist-skill` 的 Truby 有机结构论，本格式包的 STC/Story Circle/McKee 作为**补充选型**
- 人物设计可叠加 `behavior-psychology-skill` 的 OCEAN/依恋/防御机制
- 对白遵循 `dialogue-skill` + `songfangjin-skill`
- 审查时 `reviewer` 仍用 McKee+Seger 独立评分 + 对标范例
- 节奏标注使用 `structuralist-skill` 的双轨节奏系统
