# 叙事短片格式包（5-10分钟）

## 核心特征

- **时长**：5-10分钟
- **角色**：1-2个主角，有完整的 Want/Need/Arc
- **结构**：四段式（起因→发展→高潮→结局），聚焦单一核心事件
- **弧光**：一次完整的 A→B 变化
- **世界观**：简洁明了，30秒内观众理解规则
- **节奏**：信息密度高，每个场景都必须推进情节或揭示性格

## 短片的核心约束

短片只允许一个"单一核心事件"，不能有支线、不能分散焦点。所有场景都服务于同一个戏剧动作——主角追求目标、遭遇阻碍、做出选择。

除非用户特别要求，所有设定都应发生在现实主义背景下，禁止过于夸张或戏剧性的设计。

---

## 人物深度（短片级）

短片不需要完整的 Ghost/Lie/Flaw，但需要：
- **Want**：驱动动作的外部目标
- **Need**：角色未意识到的灵魂缺口
- **Arc**：从 A 状态到 B 状态的不可逆变化
- **矛盾特征**：外在表现 vs 内在真实（至少一层）

如果人物感觉"太平了"，可以借用长片的 Ghost/Lie/Flaw 思考方式——不需要完整展开，只需要暗示：角色的行为背后有一个不被说出的原因。一个细节就够。

---

## 前史与世界观（短片精简版）

遵循"电影是现实生活的横截面"——故事开始之前世界已经存在了。

短片编剧必须知道但不一定全部展示：
- **时代/环境背景**：故事发生在什么环境、什么社会氛围下
- **角色前史关键事件**：什么导致了当前处境和性格
- **关系既往**：重要关系在故事开始前是什么状态
- **横截面选择**：为什么从这个时刻开始讲

前史信息通过对白和视觉线索自然散落，不要集中闪回或旁白交代。

---

## 结构大纲（四段式）

```
第一幕：起因（约15%时长）
  开场钩子（前15秒的画面/动作）：
  建置（故事常态展现）：
  激励事件（打破平衡）：

第二幕：发展（约40%时长）
  冲突升级（障碍1）：
  冲突进一步升级（障碍2，不可省略）：
  中点（伪胜利/伪失败）和一切尽失：

第三幕：高潮（约25%时长）
  最终对决（动作顶点）：
  关键选择和故事反转：

第四幕：结局（约20%时长）
  新常态（弧光完成）：
```

**开场要求：** 前15秒决定生死。第一个画面就应包含信息或悬念。最有效的短片开场是一个"不太对"的日常画面——看起来正常，但某个细节让人起疑。

---

## 场景拆解

将大纲转化为具体视听单元：

```
第1场戏：...（约X秒）情节：松/中/紧 | 情感：轻/中/重
第2场戏：...（约X秒）情节：松/中/紧 | 情感：轻/中/重
...
时长累计：X分X秒 / 目标总时长X分钟
```

**短片节奏检查：**
- [ ] 相邻场景之间是否有节奏对比？
- [ ] 是否有连续 3 场以上同一节奏状态？
- [ ] 情节节奏和情感节奏是否有至少一处错位？
- [ ] 场景时长累加是否与目标总时长吻合？

---

## 短片节奏技法

### 前史展示
前史信息通过对白和视觉线索自然散落，不集中闪回或旁白交代。

### 节奏的拉伸与回弹
- **拉伸**：用重复动作、平缓语速、静态画面建立预期
- **回弹**：在毫无预警处迅速打破平衡，用极短的视听语言制造节奏断裂

### 结局
结局应展示弧光完成后的"新常态"——角色变化后的世界是什么样的。不需要解释角色学到了什么，用一个画面让观众自己感受。

### 伏笔回扣（短片缩小版）
短片只有5-10分钟，但一个精妙的伏笔回扣在短时间内冲击力反而更大——因为观众还记得。第1分钟不经意出现的物件在第8分钟突然成为关键，效果是炸裂的。

## 自检清单

### 核心概念
- [ ] 戏剧动作有效？目标合理且急切？
- [ ] 冲突是驱动故事的发动机？

### 人物
- [ ] Want 和 Need 清晰且对立？
- [ ] 有不可逆的内在变化？
- [ ] 有矛盾特征？

### 结构
- [ ] 开场前15秒有视觉钩子？
- [ ] 四段清晰？激励事件、高潮明确？
- [ ] 障碍2存在且与障碍1不同质？
- [ ] 各部分时长比例合理？

### 场景写作
- [ ] 无心理描写？无括号暗示？
- [ ] 对话有潜台词？台词口语化？
- [ ] 用画面叙事？

## 与现有技能包的关系

- 人物设计可调用 `behavior-psychology-skill` 的 OCEAN/依恋/防御工具做快速人格素描
- 对白创作遵循 `dialogue-skill` 的 Mamet 方法论
- 结构骨架可参考 `structuralist-skill` 的 Truby 有机结构论（简化版）
- 节奏标注使用 `structuralist-skill` 的双轨节奏系统
- 视听语言参照 `director-skill` 的视听语言武器库
