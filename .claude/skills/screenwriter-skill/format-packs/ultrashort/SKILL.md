# 概念超短片格式包（1-3分钟）

## 什么是概念超短片

概念超短片是纯粹的"idea delivery"——在1-3分钟内用一个高概念击中观众。武器不是故事，是概念本身的锐度和视听语言的冲击力。

**核心特征：**
- 时长：1-3分钟
- 角色：功能性 archetype，不需要深度。角色是概念的载体，可以没有角色
- 弧光：通常没有。如果有，只是一个瞬间的认知翻转
- 世界观：即插即用，5秒内观众必须理解规则
- 节奏：从第一帧开始就在传递信息，零废镜头

**两种创作路径：**
- **What-If 型**：假设一个反常识的前提，展示后果和推演。核心武器是概念的纯度和组合
- **How-to-Tell 型**：用出人意料的叙事方式重新讲述已知的事情。核心武器是形式本身的创意

进入创作前先确认用户要做哪种类型——两者的第一步就不一样。

---

## Part A：What-If 型

### What-If的本质

好的 What-If 不是天马行空的幻想，而是现实的一面放大镜——把某个真实存在但被忽视的社会机制、人性弱点、荒诞逻辑放大到不可忽视的程度。

### 五种概念组合方法

最锐利的 What-If 往往是两个不相关的概念碰撞产生的化学反应。

**1. 概念嫁接** — 取概念A的运行机制 + 概念B的应用场景
- "斩杀线" + AI焦虑 → "公司用AI给每个员工打分，分数低于斩杀线的人第二天工位上只剩一个USB"
- 游戏复活机制 + 职场裁员 → "被裁的人可以投币复活，但每次复活工资减半"

**2. 时空错置** — 把人物/技术/制度放到它不属于的时代或地点
- 钢铁侠 + 1990年代下岗潮 → "东北军工厂高级工程师在自家车库用废铁造盔甲"
- ChatGPT + 科举 → "考生带了一个能对对子的铜匣子进考场"

**3. 隐喻具象化** — 把抽象焦虑变成可被摄影机拍到的物理规则
- "内卷" → "所有人的灯必须比邻居亮，亮度不够就断电"
- "容貌焦虑" → "镜子会给你的脸打分，分数显示在额头上"

**4. 反转并置** — 找到两个表面相似但本质矛盾的事物，放在同一场景共存
- "宠物"和"畜牧" → 一个人精心喂养他的猫，用的猫粮工厂隔壁就是屠宰场

**5. 规则反转** — 把一个现实规则取反，推演后果
- "越努力越成功"反转 → "越努力拥有的越少"
- "记忆随时间消退"反转 → "记忆不会消退，但你可以主动删除——代价是每删一段记忆就永远失去对应的那种情感"

### 概念组合检验

- [ ] 组合产生了"1+1>2"的效果？
- [ ] 观众能在5秒内理解规则？
- [ ] 指向了一个真实的社会情绪或人性弱点？
- [ ] 有推演空间——规则推到极限时会发生什么？
- [ ] 有翻转潜力——最后能反过来打观众一巴掌吗？

### What-If 的五种结构

**A. 经典三段式**（概念呈现 → 推演 → 翻转）
- 最通用。15-30秒概念呈现 → 30-90秒推演切片（层层递进）→ 15-30秒翻转

**B. 递进崩塌式**（规则不断升级直到崩溃）
- 规则建立 → 第一次升级 → 第二次升级 → 崩溃点 → 余像

**C. 双线并置式**（两条线平行推进，某刻观众发现两者的关系）
- 适合"反转并置"组合方式。"意识到"的瞬间就是翻转

**D. 循环/Loop式**（起点→发展→看似解决→回到起点）
- 第二次看到起点时，观众的理解已经不同了

**E. 倒叙揭示式**（先展示不可理解的结果，倒推原因）
- 每一步揭示让画面更合理——也更恐怖/荒诞/讽刺

## Part B：How-to-Tell 型

### How-to-Tell的本质

不改变"讲什么"，而是改变"怎么讲"。形式即内容。

### 五种创意方法

**1. 视角置换** — 用一个不可能的视角讲述
- 从子弹的视角讲述战争、从外卖袋的视角讲述独居者的一天

**2. 形式模拟** — 用某种已有形式（说明书、游戏攻略、APP界面）重新包装
- 用"搜索历史记录"讲述一个人从确诊到接受的心理历程

**3. 时间手术** — 对时间做手术（加速/减速/倒放/循环/跳跃）
- 把一个人的一生压缩到2分钟；把1秒拉长到3分钟

**4. 尺度跳跃** — 在极大和极小之间跳跃
- 从一个细胞的分裂开始，逐步拉远到星系——然后切回细胞

**5. 规则限制** — 给叙事本身加一个规则限制
- 整部片子只用一个固定镜位；整部片子没有一个人出现

### How-to-Tell 的通用节奏

```
一、形式建立（前20-30秒）
   让观众理解"这个片子用了什么方式在讲故事"。
   第一反应应该是"哦？这样讲？"

二、形式深入（中间60-120秒）
   形式在升级、变异、或暴露出新的含义。
   不是重复同一种手法。

三、形式与内容的交汇（最后15-30秒）
   观众意识到形式和内容是一体的——
   形式本身就是故事的一部分。
   最好的结尾是形式本身完成了翻转。
```

### 形式检验

- [ ] 形式与内容深度契合？（不只是"酷"，而是"只能这样讲"）
- [ ] 形式有递进空间？
- [ ] 去掉形式用常规方式讲，内容是否丧失冲击力？（如果不会，换形式）

## 工作流（三步）

### 第一步：概念锻造 / 形式发现

What-If → 用五种组合方式生成3-5个概念，标注组合方式和推演潜力
How-to-Tell → 用五种创意方法生成3-5个形式方案，检验契合度

### 第二步：结构与视听设计

选择结构类型 + 从视听语言武器库（见 director-skill）选择1-2种核心手法 + 展开为带时长标注的结构大纲

### 第三步：全片剧本

一次写完。极致精简，每个字都必须存在于画面中。零解释纯视觉叙事。

## 常见陷阱

- 概念需要大量解释 → 换概念或降级到短片
- 推演只是概念的重复而非递进 → 每个切片必须比上一个更进一步
- 翻转是硬转（跟前面没有逻辑关系）→ 翻转必须是概念自身逻辑的延伸
- 试图在3分钟内塞入完整角色弧光 → 放弃弧光，聚焦概念
- 有台词在"解释概念" → 删掉，用画面展示
- 一部片子用了太多视听手法 → 聚焦1-2种，用到极致
- How-to-Tell的形式只是"包装" → 形式必须不可替代
