# 编剧技能包（Kasdan + Gilroy 方法论）

## 技能概述

本技能包封装了两位大师的核心方法论：

- **Lawrence Kasdan**：人物驱动叙事，对白揭示性格而非推进情节，每场戏都在改变人物关系，结局必须从第一幕开始就埋下
- **Tony Gilroy**：信息不对称是张力的根源，主角永远比观众少知道一件事，道德困境没有正确答案，机构/体制是真正的反派

## 核心方法论

### 一、场景写作铁律（Kasdan）

**每场戏必须完成三件事之一：**
1. 改变人物关系（更近或更远）
2. 揭示新信息（改变观众对已知事实的理解）
3. 推进不可逆的决定（角色做了不能撤回的事）

**如果一场戏三件事都没做，删掉它。**

场景进入原则：
- 进入时间越晚越好——从冲突已经开始的地方进入，不要铺垫
- 离开时间越早越好——高潮过后立刻切出，不要收尾

场景结束方式：
- ✅ 以动作结束（她关上了门）
- ✅ 以问题结束（他看着手里的地址，没有动）
- ✅ 以沉默结束（两人都没有说话）
- ❌ 以解释结束（"这就是为什么我..."）
- ❌ 以宣言结束（"我决定了..."）

---

### 二、对白设计铁律（Kasdan + Gilroy）

**对白的唯一功能：揭示角色，而不是传递信息。**

信息传递用视觉手段（道具、动作、环境），对白说的永远是"别的事"。

**Kasdan 的潜台词原则：**
每句对白都有表层和深层两个含义。
- 表层：字面意思
- 深层：角色真正想说的

示例：
- "你吃了吗？" ← 表层：关心饮食；深层：我需要你留下来
- "路上小心。" ← 表层：安全叮嘱；深层：我不知道该说什么

**Gilroy 的信息克制原则：**
观众获得信息的顺序比信息本身更重要。
- 让观众先于某个角色知道某件事 → 制造悬疑
- 让角色先于观众知道某件事 → 制造谜题
- 两者同时获知 → 最弱的叙事方式，尽量避免

**对白禁忌：**
- ❌ 解释动机："我这样做是因为..."
- ❌ 描述情绪："我现在很难过/愤怒/害怕"
- ❌ 总结刚发生的事："所以你的意思是..."
- ❌ 哲学宣言："人生就是这样..."
- ❌ 确认已知信息（对白版的"你也知道"）

---

### 三、人物设计铁律（Kasdan）

**主角的定义：必须改变，或者必须拒绝改变并付出代价。**

人物弧线不是"从坏人变好人"，而是：
- 核心信念在压力下被检验
- 信念被证伪，人物改变
- 或信念被坚守，人物付出代价

**人物的三个维度：**
1. 他们做什么（行为）
2. 他们说什么（语言）
3. 这两者之间的落差（性格）

落差就是角色。行为和语言完全一致的人在剧本里是平的。

**配角设计原则（Gilroy）：**
每个配角都有自己的目标，这个目标和主角的目标在某个时刻必须冲突。
没有纯粹的帮手，没有纯粹的障碍，只有有自己目标的人。

---

### 四、结构铁律（Gilroy）

**每集/每章必须包含：**
- 开场钩子（30秒-1分钟内建立悬念）
- 中段压力点（主角的选择被迫升级）
- 结尾钩子（新问题出现，或已知问题的新角度）

**钩子密度标准：**
- 每3-4分钟/每500-800字：一个钩子
- 开场：必须有
- 中段：至少一个
- 结尾：必须有

**钩子类型：**
| 类型 | 定义 | 示例 |
|------|------|------|
| 信息钩 | 观众知道角色不知道的事 | 镜头切到门口有人在监视 |
| 选择钩 | 角色被迫在两个坏选项中选 | 要么签字，要么他死 |
| 反转钩 | 已知信息被重新解释 | 原来他一直知道 |
| 时间钩 | 倒计时或截止日期 | 三小时后引擎失效 |
| 关系钩 | 两个人的关系发生不可逆变化 | 她关上门，没有回头 |

---

### 五、审查标准（Kasdan + Gilroy 联合视角）

对每集/每章的完成稿进行以下检查：

**Kasdan 审查维度：**
- [ ] 每场戏都在改变人物关系或揭示新信息？
- [ ] 对白有潜台词，不是直接说出情绪？
- [ ] 主角有明确的核心信念，并在本集受到检验？
- [ ] 结尾和开头在主题上形成呼应？

**Gilroy 审查维度：**
- [ ] 信息分配制造了张力（观众和角色的信息不对称）？
- [ ] 道德困境没有正确答案？
- [ ] 机构/体制/规则在阻碍主角（不只是个人对立）？
- [ ] 钩子密度达标（每3-4分钟一个）？

**评分维度（各25分，满分100）：**
1. 场景效率（每场戏都有功能）
2. 对白质量（潜台词、个性化、不说废话）
3. 信息张力（信息分配制造悬念）
4. 钩子密度（开场/中段/结尾都有钩子）

---

### 六、时长估算与预算（所有格式通用）

**每场戏都应标注预估时长。** 时长不只是"这场戏多长"，更是"这场戏在全片节奏中占多大比重"。

**时长估算方法：**
- 纯对话场景：中文约 200-250 字对白+动作描写 ≈ 1 分钟
- 动作/蒙太奇：按画面数量（每个独立画面约 3-5 秒）
- 沉默/情绪场景：容易低估——角色站着不动在成片中可能需要 10-15 秒
- 转场/过渡：每次 2-5 秒，不要忘记计入

**场景标注格式：**

```
【场景3：医院走廊 / 夜 / 荧光灯嗡嗡响】（约1分30秒）
  情节节奏：中 | 情感节奏：重
```

**全片/全集时长预算（参考比例）：**

| 格式 | 建置 | 发展前半 | 发展后半 | 高潮 | 结局 |
|------|------|---------|---------|------|------|
| 短片（8分钟） | 1.5分 | 2分 | 2分 | 1.5分 | 1分 |
| 长片（100分钟） | 25分 | 30分 | 25分 | 15分 | 5分 |
| 剧集单集（25分钟） | 4分 | 10分 | 6分 | 3分 | 2分 |
| 短剧单集（3分钟） | 20秒 | 70秒 | 40秒 | 30秒 | 20秒 |

**时长诊断清单（剧本医生阶段）：**
- [ ] 高潮段时长是否足够？（太短会让高潮被压缩）
- [ ] 建置是否太长？（观众等太久才进入正题）
- [ ] 连续超过 3 分钟的单一情绪段落？
- [ ] 两个高情感场景之间有足够呼吸空间？
- [ ] 全片最长的单场戏是否有足够理由占那么多时长？

---

### 七、写作红线（全局最高优先级）

**绝对不要：**
- 写心理描写（"他意识到"、"她领会到"、"内心涌起"）
- 写括号暗示（"（其实是在掩饰紧张）"）
- 角色用台词解释设定或主题
- 说教片段、强行催泪、煽情独白
- 过度比喻句、类比、书面化的 AI 腔台词
- 在剧本中写任何无法被摄影机拍到的内容

**必须做到：**
- 台词口语化，像真人说话
- 用动作代替解释（动作即潜台词）
- 对话像冰山，只露一角
- 所有内容从视听角度出发

**输出前自检：** 所有内容输出前必须内部过一遍写作红线。如果发现违反，先修改再输出。

## 文件结构

```
screenwriter-skill/
├── SKILL.md                    # 本文件（基础方法论 + 时长估算 + 写作红线）
├── references/
│   ├── structure.md            # 故事结构方法论（起承转合 + 三幕）
│   ├── hook-design.md          # 钩子设计详解（含按类型分策略的开场钩子）
│   ├── dialogue-rules.md       # 对白规则详解
│   ├── scene-writing.md        # 场景写作详解
│   └── checkpoint-system.md    # 记忆检查点系统（长内容防丢失）
├── style-packs/                # 风格包（叠加质感约束）
│   ├── serious-drama/          # 严肃叙事风格包
│   │   └── SKILL.md
│   └── genre-thriller/         # 类型悬疑风格包
│       └── SKILL.md
└── format-packs/               # 格式包（按体量加载）
    ├── ultrashort/             # 概念超短片（1-3分钟）
    │   └── SKILL.md            #   What-If / How-to-Tell 双路径
    ├── short-film/             # 叙事短片（5-10分钟）
    │   └── SKILL.md            #   四段式结构、单一核心事件
    ├── feature-film/           # 电影长片（75-120分钟）
    │   └── SKILL.md            #   STC/Story Circle/McKee/内在节拍 + 风格变体
    └── series-extended/        # 剧集扩展工具
        └── SKILL.md            #   连续性追踪、弧光预算、信息释放、集间节奏
```

### 格式包加载规则

根据项目体量，在创作启动时加载对应格式包：

| 项目体量 | 加载格式包 | 说明 |
|---------|-----------|------|
| 1-3分钟概念片 | `format-packs/ultrashort/` | 概念组合 + 视听设计 |
| 5-10分钟短片 | `format-packs/short-film/` | 四段式 + 短片节奏 |
| 75-120分钟长片 | `format-packs/feature-film/` | 结构选型 + Subplot + 伏笔 |
| 多集剧集 | `format-packs/series-extended/` | 叠加在现有剧集系统上 |

格式包和风格包可以叠加使用（如：长片格式包 + 严肃叙事风格包）。

## 调用方式

在任何剧本创作阶段，读取本文件后：
1. 根据当前任务（写作/审查/改编）选择适用的方法论部分
2. 如有风格包需求，读取对应 `style-packs/` 下的 SKILL.md 叠加风格约束
3. 执行创作或审查任务
