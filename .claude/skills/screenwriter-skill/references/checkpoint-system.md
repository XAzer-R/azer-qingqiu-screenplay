# 记忆检查点系统（长内容防丢失）

## 为什么需要记忆检查点

长片剧本约 15000-25000 字，剧集全季可达 10 万字以上。创作过程中，前面写的场景、埋下的伏笔、角色的状态变化，可能在写到后面时被"遗忘"，导致前后矛盾、伏笔断裂、角色行为失去连续性。

记忆检查点通过定期生成结构化的"快照"来解决——每到一个节点，把已完成部分的关键信息压缩为简洁的摘要，作为"记忆锚点"使用。

---

## 何时触发检查点

| 格式 | 触发时机 | 说明 |
|------|---------|------|
| 概念超短片 | 不需要 | 内容短，不会超出上下文 |
| 短片 | 场景拆解完成后触发一次 | 进入写作前锁定全局信息 |
| 长片 | 每完成一个 Sequence（2-3场戏）触发一次 | 约每 10-15 分钟成片内容一个检查点 |
| 剧集 | 每完成一集触发一次；单集超过 6 场戏时中间也触发 | 集间检查点最重要 |

**额外触发时机：**
- 用户开始新一轮对话但要继续之前的创作
- 已经写了很多内容，感觉前面的细节开始模糊
- 用户主动要求"总结一下目前的进度"

---

## 通用检查点模板

```
═══════════════════════════════════
记忆检查点 #[编号] | [格式] | [当前位置]
═══════════════════════════════════

【已完成进度】
  当前处于第几步 / 已写到哪个场景或段落

【故事核心（不变）】
  Logline：
  主题论点（如有）：
  核心戏剧动作：目标 → 阻碍

【角色当前状态】（每个主要角色一行）
  [角色名]：物理状态 / 情感状态 / 当前知道什么 / 当前想要什么

【已完成段落摘要】（每个已完成场景/序列一句话）
  场景1：[一句话概括 + 核心价值转变]
  场景2：...

【活跃线索】（当前正在运行的、后续必须回应的线索）
  - [线索1]：状态描述
  - [线索2]：状态描述

【伏笔状态】
  已埋未回扣：[伏笔内容] → 计划在[位置]回扣
  已回扣：[伏笔内容] ✅

【节奏状态】
  上一段落的情节节奏：松/中/紧
  上一段落的情感节奏：轻/中/重
  → 下一段落建议：[节奏方向]

【待写内容预告】
  下一个要写的场景/段落是什么
  这个段落的核心戏剧动作是什么

═══════════════════════════════════
```

## 长片检查点（额外字段）

```
【Subplot状态】
  A Plot进度：[当前位置/全片位置]
  B Plot进度：
  C Plot进度（如有）：

【弧光进度】
  角色当前处于弧光的哪个阶段：
  Lie是否被质疑过？质疑了几次？
  上一次伪变化发生在哪里？

【世界观已揭示层】
  观众目前知道世界观的哪一层？
  下一层计划在哪里揭示？

【结构定位】
  当前处于哪个节拍？
  距离下一个关键节拍还有多少时长？
```

## 剧集检查点（分两级）

### 集间检查点（每完成一集触发，最重要）

```
【本集完成摘要】
  本集Logline：
  本集核心事件：
  本集弧光消耗：角色变化了什么？累计进度？

【连续性追踪更新】
  角色状态变化：[与上一集的对比]
  暗线推进：本集推进了什么？
  新埋的种子：
  回扣的种子：
  新公开的信息：

【季度进度】
  当前处于季度四阶段的哪个阶段？
  弧光预算已消耗多少？
  下一集的分集大纲核心是什么？
```

### 集内检查点（单集内容较长时触发）

使用通用模板即可，重点记录本集内部的角色状态和活跃线索。

## 检查点压缩原则

- **只记结论，不记过程。** "场景3：老王在医院发现了女儿的秘密，价值从信任→怀疑"——不复述对白和动作。
- **只记变化，不记不变。** 如果某个角色没有变化，不重复其状态。
- **只记后续需要的信息。** 已完成且不再影响后续的情节点，可以压缩为一句话甚至省略。
- **活跃线索和伏笔是最重要的。** 这些最容易被"遗忘"，必须每个检查点都完整列出。

---

## 如何使用检查点

**写作时：** 每次开始写新段落之前，先回顾最近的检查点——确认角色状态、活跃线索、节奏方向。

**跨对话时：** 如果用户在新对话中要求继续创作，先请用户提供上次检查点，以此为基础恢复上下文。

**剧本医生时：** 把所有检查点串起来通读，可以快速发现：
- 某条伏笔埋了但一直没回扣
- 某个角色的状态在两个检查点之间突然跳变（连续性错误）
- 节奏长时间没有变化
- 某条 Subplot 长时间没有推进

## 触发时的标准话术

> 到这里先建一个记忆检查点，把目前的进度锁定一下。
> [输出检查点内容]
> 你可以保存这个检查点。如果后续对话中断或上下文太长，把这个检查点贴回来就能继续。
