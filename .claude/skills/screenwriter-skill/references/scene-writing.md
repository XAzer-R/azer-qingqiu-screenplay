# 场景写作方法论

## 核心原则

每场戏都是一个微型故事：有进入状态、有转折、有离开状态。

**进入状态 ≠ 离开状态**——如果进出状态相同，这场戏没有存在的意义。

---

## 一、场景的三要素

### 1. 目标（Goal）
每个角色进入这场戏时想要什么？
- 必须具体（不是"想要解决问题"，是"想要他签那份文件"）
- 目标之间必须冲突（A想要X，B不想给X）

### 2. 障碍（Obstacle）
什么阻止角色实现目标？
- 最好的障碍来自另一个角色的目标
- 次好的障碍来自环境/规则/时间
- 最弱的障碍来自主角自己的犹豫

### 3. 转折（Turn）
这场戏结束时，情况如何改变？
- 目标实现了，但产生新问题
- 目标失败了，但获得新信息
- 目标意外转变了

---

## 二、场景进入与离开

**进入原则：越晚越好**
- 从冲突已经开始的地方进入
- 不要铺垫，不要建立背景
- 背景信息通过对话和动作自然浮现

**离开原则：越早越好**
- 高潮过后立刻切出
- 不要收尾，不要解释
- 让最后一个动作或沉默说明一切

**示例：**
```
❌ 错误进入：
   陈光明走进公司，跟同事打招呼，坐下来，打开电脑，收到一封邮件...

✅ 正确进入：
   陈光明盯着屏幕上的邮件。裁员名单。第三行是他师傅的名字。

❌ 错误离开：
   两人沉默了一会儿，最终王丽还是点了点头，离开了房间。陈光明看着她离开，心里很复杂...

✅ 正确离开：
   王丽站起来，把文件推回桌上，走了。
   门关上了。
```

## 三、场景的物理细节

每一个物件、每一个空间都必须有叙事功能。

**物件的四种功能：**

| 功能 | 说明 | 示例 |
|------|------|------|
| **性格延伸** | 物件反映角色性格 | 整洁到变态的桌面=控制欲 |
| **关系标记** | 物件记录关系状态 | 两人之间唯一的那杯咖啡 |
| **伏笔载体** | 物件在后面有意义 | 抽屉里那把钥匙 |
| **情绪外化** | 用物件代替情绪词 | 杯子在桌上划了一道=紧张 |

**空间的叙事功能：**
- 谁占据空间的核心位置 = 谁有权力
- 空间的大小/高低 = 人物的处境
- 空间的整洁/混乱 = 人物的心理状态

---

## 四、场景的感官层次

每场戏至少覆盖三个感官层次：

| 感官 | 剧本中的写法 | 影视中的功能 |
|------|------------|------------|
| **视觉** | 主要动作和状态 | 建立空间感 |
| **听觉** | 环境音、机械音、沉默 | 建立情绪底色 |
| **触觉** | 动作的质感（粗糙/光滑/冷/热） | 让场景可感知 |

**感官细节的写法：**
```
❌ "她很紧张地坐在那里。"

✅ "她坐在椅子边沿，双手在桌下交叠。
   走廊里有打印机的声音。
   空调的冷气从她右肩吹下来。"
```

---

## 五、动作描述规范

### 动作描述的颗粒度

**剧本的动作描述比小说更具体，比导演说明更克制。**

描述的是"发生了什么"，不是"怎么拍"。

```
❌ 太抽象："她紧张地等待着。"
❌ 太具体（导演说明）："摄影机缓慢推近，焦点在她颤抖的手上。"
✅ 正确颗粒度："她把表翻过来，表盘朝下。"
```

### 动作代替情绪词

每一个情绪词（紧张/愤怒/悲伤/兴奋）都必须转化为具体动作：

| 情绪词 | 转化为动作 |
|------|---------|
| 紧张 | 杯底在桌面上划了一下 |
| 愤怒 | 他把文件放下，没有摔 |
| 悲伤 | 她的眼睛看着右上方 |
| 兴奋 | 她往前走了一步，然后停住了 |
| 困惑 | 他把那句话读了两遍 |
| 决定 | 她关上了抽屉 |

## 六、场景节奏控制

### 张力建立

张力来自信息不对称，不来自激烈程度。

```
低张力：两个人在吵架（激烈，但信息对称）
高张力：两个人在平静地谈事情，但观众知道其中一人撒了谎（平静，但信息不对称）
```

### 节奏变化

一场戏内的节奏应该有变化：

```
快节奏段落 → 突然的停顿 → 慢节奏段落 → 突然加速
```

**制造停顿的方法：**
- 角色做一个非语言动作
- 沉默
- 话题突然转换
- 一个问题被回避了

---

## 七、场景的开头和结尾

### 开头
- 第一句话或第一个动作必须建立当前状态
- 不铺垫，直接告诉观众"现在在哪里，谁在这里，他们的关系是什么"
- 用最少的信息建立最清晰的场景

### 结尾
- 最后一个动作比最后一句台词更有力
- 以问题结尾（没有答案的行动）
- 不解释这场戏意味着什么

**结尾的有效形式：**
```
✅ 她关上了门。（动作结尾）
✅ 他看着那张纸，没有动。（状态结尾）
✅ 两人都没有说话。（沉默结尾）
❌ "我们以后再说。" / "好吧，那就这样了。"（收尾台词，是最弱的结尾）
```
