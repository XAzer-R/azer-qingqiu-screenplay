# 对白规则方法论

## 核心原则

**对白的唯一功能是揭示角色，不是传递信息。**

信息用视觉传递（道具、动作、环境）。
对白说的永远是"别的事"。

---

## 一、潜台词设计

每句有效的对白都有两层含义：

| 层次 | 定义 | 设计方法 |
|------|------|---------|
| **表层** | 字面意思 | 角色说出口的话 |
| **深层** | 真正想说的 | 角色说不出口/不愿说出口的话 |

**潜台词设计步骤：**
1. 确定角色真正想说什么（深层）
2. 找一个表层话题，让两者产生关联但不直接
3. 让角色只说表层，观众感受到深层

**示例分析：**
```
表层对话：
A："你吃了吗？"
B："不饿。"

深层含义：
A：我需要你留下来，我不知道怎么开口。
B：我知道你想说什么，但我还没准备好听。
```

## 二、个性化对白

每个角色的说话方式必须独特，遮住名字也能知道是谁说的。

**个性化的五个维度：**

| 维度 | 描述 | 设计方法 |
|------|------|---------|
| **词汇** | 用词习惯，行话，禁忌词 | 军人说指令，学者说概念，市民说俚语 |
| **句式** | 长句还是短句，完整还是省略 | 焦虑的人说话没有逻辑，冷静的人一句顶三句 |
| **回避** | 不说什么，绕开什么 | 什么话他永远不会说 |
| **节奏** | 停顿，打断，抢话 | 强势的人打断别人，弱势的人让别人打断 |
| **谎言方式** | 怎么说谎，用什么掩盖 | 有人改变话题，有人给更多细节，有人反问 |

**禁忌：**
- ❌ 所有角色用同样的句式说话
- ❌ 解释性对白（"正如你所知道的..."）
- ❌ 说话时没有目的（角色说话是为了说话，不是为了达成什么）

---

## 三、对白中的沉默

沉默是对白的一部分，有时比台词更有力。

**沉默的功能：**
- 角色不知道说什么（真实的困惑）
- 角色知道说什么但不敢（压抑）
- 角色在评估说什么最安全（策略）
- 角色在感受刚才说的话的重量（情绪）

**沉默的写法：**
```
✅ （沉默。）
✅ 她没有说话。
✅ 他看着窗外。

❌ （沉默，两人都不知道该说什么，空气凝固了。）
```

写沉默，不解释沉默。

---

## 四、对白的功能检查

每一句台词必须完成以下至少一项：

1. **揭示性格**：让观众更了解这个人
2. **推进冲突**：改变两人之间的关系张力
3. **埋下伏笔**：一句话在后面有回响
4. **建立信息不对称**：说了一半，留下一半

**如果一句台词一项都没做，删掉它。**

## 五、常见对白病症及修复

### 病症1：解释动机
```
❌ "我这样做是因为三年前你对我做的那件事，我一直没有原谅你。"
✅ "三年了。" （然后她离开。）
```

### 病症2：描述自己的情绪
```
❌ "我现在真的很愤怒。"
✅ "你说完了？" （冷静得让人不安。）
```

### 病症3：总结刚发生的事
```
❌ "所以你的意思是，他其实一直知道真相，但他选择了隐瞒？"
✅ 直接推进，不要在台词里复述
```

### 病症4：哲学宣言
```
❌ "人生就是这样，有些事没有办法的。"
✅ 把这个主题用一个动作表达
```

### 病症5：对话太顺畅
真实的对话不顺畅。人们：
- 打断彼此
- 不直接回答问题
- 说到一半换话题
- 听错或假装没听到

```
❌ A："你怎么看这件事？" B："我觉得我们应该..."
✅ A："你怎么——" B："我知道你想说什么。" A："你不知道。"
```

## 六、影视剧本对白的特殊规则

### 视觉优先原则
能用画面说的，不用对白说。

```
❌ "你看起来累了。"
✅ 她的手在杯子上收紧，咖啡已经凉了。
```

### 台词简短原则
剧本台词比小说对话短50%。

```
❌ "我今天去了医院，检查结果出来了，不太好，医生说需要进一步检查，可能需要手术，但他也不确定..."
✅ "结果出来了。"
   （停顿。）
   "不好。"
```

### 信息分层原则
一句台词只传递一个核心信息。

```
❌ "他死了，是被杀的，凶手可能是他的合伙人，因为他们三个月前有过纠纷。"
✅
第一场戏："他死了。"
第二场戏：凶器是什么
第三场戏：合伙人的纠纷
```
